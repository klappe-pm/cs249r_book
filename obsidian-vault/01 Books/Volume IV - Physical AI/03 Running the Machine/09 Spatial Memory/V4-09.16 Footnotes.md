# V4-09.16 Footnotes

[[Home|Home]] · [[01 Books/Volume IV - Physical AI/Volume 4 Overview|Volume Overview]] · [[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09 Spatial Memory|V4-09 Spatial Memory]]

^footnotes

<sup>1</sup> **Belief State**: Åström ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-astrom1965optimal|1965]]) showed that a controller that cannot observe its state directly loses nothing by acting on the conditional distribution of that state given everything observed so far, the formalization encountered in **[[01 Books/Volume IV - Physical AI/02 Teaching the Machine/06 Policy Training/V4-06.06 Physical Channels of the Sim-To-Real Gap#^sec-training-privileged-distillation|Teacher-student privileged state distillation and asymmetric actor-critic]]** as a partially observable decision problem. However, an abstract mathematical distribution carries no native reference frame, evidence epoch, or error-growth model. A physical runtime requires all three to verify whether a clearance corridor remains valid during a sensor dropout.

^fn1

<sup>2</sup> **Kalman Filter**: Stanley Schmidt’s group at NASA Ames took up Kálmán’s paper shortly after it appeared and, for circumlunar navigation studies, linearized the nonlinear measurement equations about the current estimate ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-smith1962application|Smith et al. 1962]]), the reformulation now called the extended Kalman filter. MIT’s Instrumentation Laboratory then carried the filter into Apollo’s on-board navigation in a square-root form suited to a computer with a short word length ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-mcgee1985discovery|McGee and Schmidt 1985]]). The recursion fit that computer because it keeps only the latest estimate and its covariance, never the measurement history, and the same property lets spatial memory hand a consumer one dated record instead of a log to replay.

^fn2

<sup>3</sup> **Data Association in Clutter**: Radar tracking met this problem first. Bar-Shalom and Tse ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-barshalom1975tracking|1975]]) showed that a filter which commits to the single nearest return inside its gate can follow clutter and lose the target, and they weighted every gated return by its probability of having come from the target instead. A tracker that commits to one assignment per frame, as this one does, reveals a wrong pairing only through inconsistent innovations, so a confirmed track’s covariance must still pass the tests of [[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.03 Estimating State from Dated Measurements#^sec-memory-estimator-consistency|section 9.2.1]].

^fn3

<sup>4</sup> **Clock Synchronization Bound**: Controller Area Network with Flexible Data-Rate (CAN FD) bit-phase synchronization aligns bit sampling within one frame; it does not align the distributed clocks that date physical observations. Precision Time Protocol and EtherCAT Distributed Clocks provide synchronization mechanisms, but their names alone do not establish the deployed error bound, which only a measurement under the stated load and fault conditions supplies.

^fn4

<sup>5</sup> **SLAM**: Smith et al. ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-smith1990estimating|1990]]) showed that when a moving robot observes landmarks relative to itself, every landmark estimate inherits the common error in the robot’s pose, so map error and pose error are correlated and must be estimated together. The acronym came later, in a survey presented at the 1995 International Symposium on Robotics Research ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-durrant2006simultaneous|Durrant-Whyte and Bailey 2006]]). That correlation is why a loop closure moves remembered cells that no sensor has revisited.

^fn5

<sup>6</sup> **Occupancy Grid**: Moravec and Elfes built the first grids at Carnegie Mellon to fuse returns from wide-beam sonar, whose single echo cannot say where across its beam the reflector lies ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-moravec1985high|Moravec and Elfes 1985]]). Each cell therefore holds accumulated evidence rather than geometry, and a cell no return has reached stays at its prior. The representation was designed for sensors too coarse to vouch for what they did not touch, which is why a permission-grade grid must keep unknown distinct from free.

^fn6

<sup>7</sup> **Truncated Signed Distance Field**: Curless and Levoy ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-curless1996volumetric|1996]]) averaged many range scans into a signed distance stored only near the surface to build detailed models of real objects, and KinectFusion ran the same fusion in real time on a GPU from a handheld depth camera ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-newcombe2011kinectfusion|Newcombe et al. 2011]]). Truncation bought both systems their memory savings. It makes the TSDF a representation for reconstructing surfaces, not for certifying the empty space between them.

^fn7

<sup>8</sup> **Voxel Traversal**: Amanatides and Woo ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-amanatides1987fast|1987]]) step a ray from one voxel boundary to the next by comparing the distances to the next crossing on each axis and adding one fixed increment, so each voxel visited costs a few comparisons and one addition. The work per ray is therefore proportional to the number of voxels it crosses, range divided by pitch, which is the ${d_{\text{ray}}}/{r}$ factor of [[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.07 Certified Spatial Assertions in Scene Memory#^eq-mem-dram-bandwidth|equation 11]].

^fn8

<sup>9</sup> **Log-Odds**: Storing $\ell = \ln\big({p}/(1-{p})\big)$ turns each Bayesian occupancy update into an addition, with an uninformed prior at $\ell = 0$. A cell no ray has touched and a cell that received as many hits as misses both read $\ell = 0$, so the value alone cannot separate never observed from observed and ambiguous. The manifest of [[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.07 Certified Spatial Assertions in Scene Memory#^tbl-09-schema-volumetric-belief|table 2]] therefore carries an explicit `cell_state`.

^fn9

<sup>10</sup> **Walking Approach Speed**: ISO 13855 positions a safeguard at ${S} = {v_h}\,{T} + {C}$ from a hazard, where ${T}$ is the overall stopping time, ${C}$ is an intrusion allowance, and ${v_h}$ is the approach speed (1.6 m/s for a walking body) ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-iso13855|International Organization for Standardization 2024]]). ${v_h}$ is a design convention the standard adopts, not a measured human maximum, and a person who runs exceeds it. The rack-end deadline therefore inherits a site premise, that nobody in the aisle moves faster, which the site must enforce or qualify.

^fn10

<sup>11</sup> **Non-Smooth Contact Dynamics**: Coulomb friction is set-valued at zero sliding speed, and a switch between stick and slip changes the contact dynamics. An impact can also change velocity abruptly. A smooth drift model qualified for one contact regime does not automatically bound these transitions. The belief record therefore treats a change of contact mode as leaving its validity region ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.11 The Belief Record Schema#^sec-memory-spatial-state-schema|section 9.10]]), not as one more bounded disturbance.

^fn11

<sup>12</sup> **Observability Rank Test**: For the force-plus-bias state with ${\mathbf{H}} = [1\;\,1]$ and static dynamics ${\mathbf{F}} = {\mathbf{I}}$, Kalman’s observability matrix stacks ${\mathbf{H}}$ and ${\mathbf{H}}{\mathbf{F}}$. Because these two rows are identical, the matrix has rank one rather than two ([[01 Books/Volume IV - Physical AI/03 Running the Machine/09 Spatial Memory/V4-09.15 Source References#^ref-kalman1960general|Rudolf E. Kalman 1960]]). The unobservable direction corresponds to an equal increase in contact force and decrease in sensor bias, a mode that no number of scalar samples can resolve. Restoring full rank requires an independent sensing channel, an active excitation, or an external reference load.

^fn12
