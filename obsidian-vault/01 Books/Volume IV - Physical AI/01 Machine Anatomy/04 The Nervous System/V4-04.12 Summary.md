# V4-04.12 Summary

[[Home|Home]] · [[01 Books/Volume IV - Physical AI/Volume 4 Overview|Volume Overview]] · [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/04 The Nervous System/V4-04 The Nervous System|V4-04 The Nervous System]]

^sec-nervous-summary

**[[01 Books/Volume IV - Physical AI/01 Machine Anatomy/02 The Physical Body/V4-02 The Physical Body#^sec-body|The Physical Body]]** derived the physical stopping budget for the loaded machine, and **[[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03 The Cognitive Brain#^sec-brain|The Cognitive Brain]]** established the operational cadences for proposal generation and evidence age. This chapter introduced the real-time permission path designed to enforce those constraints, establishing a two-processor architecture whose physical isolation still awaits evaluation under load. To guarantee deterministic safety, the permission path holds exclusive write access to the motor drive registers. It communicates with the unprivileged proposal engine through a lock-free mailbox that never stalls the high-frequency control tick, while communication and computation delays mandate closing joint-level feedback loops directly within the drives. By evaluating command interfaces, from joint positions to operational-space impedances, the permission path prices each check against available stopping clearance. Combining these constraints yields a bounded time window during which an action proposal is permitted to drive physical actuators. On the running machine, this analysis produces a chunk lease that exceeds the proposer’s renewal interval while fitting within the pre-brake delay budget. The resulting handoff record documents this lease alongside its validity conditions and evidence requirements. This lease and the mechanisms behind it remain claims until they are verified under worst-case compute jitter, bus contention, malformed proposals, sensor faults, and degraded braking. **Key Takeaways: The permission path and determinism**

- **The permission path alone writes the drives:** Learned models act only as unprivileged proposal engines (${p}_t$). Write access to the motor drive registers belongs to the deterministic real-time enforcer alone, hosted on silicon whose isolation from the proposer must be verified experimentally.
- **Cadence is dictated by physics, not software:** The four-tier concurrency hierarchy (20 kHz FOC current regulation, 1 kHz kinematic enforcer checks, 20 Hz action-chunk renewal, and 2 Hz multimodal deliberation on the running machine) is governed by physical time constants (${\tau_e} = {L_{\text{phase}}}/{R_{\text{phase}}}$), total loop delay, exposure horizons, and model execution budgets. The total loop delay appears as a phase lag ${\Delta \phi} = {\omega_c}({T_s}/2 + {T_{\text{comp}}} + {T_{\text{bus}}})$, which keeps the joint loops in the drives.
- **The exchange never waits, and every proposal expires:** The permission path reads the mailbox in a single bounded attempt per tick, retaining the currently active, independently admissible chunk if a write collision occurs. Every proposal carries an evidence timestamp and an explicit expiration horizon that terminates its authority even if an explicit cancellation never arrives.
- **Stopping dynamics dimension the chunk lease:** For the mobile manipulator operating at its drive limits, the pre-brake ceiling is 258.3 ms. Sizing the lease at 60 ms places it just above the proposer’s renewal floor. The interval from the final admitted chunk to brake onset takes 82 ms. Its lease path brings the stopping budget’s running total to 835.5 mm of the 1.10 m clear distance before evidence age and the remaining stop margins are charged (row 4 of **[[01 Books/Volume IV - Physical AI/03 Running the Machine/12 Safety Enforcement/V4-12.04 Stopping Envelopes#^tbl-enforcement-stopping-budget|The warehouse mobile manipulator's stopping budget]]**).
- **Worst-case bounds outrank empirical distributions:** Tail-latency percentiles such as $\text{p99}$ cannot establish real-time safety. Deterministic enforcement requires bounding worst-case computation, blocking, and interference (${R}_i = {C}_i + {B}_i + {I}_i \le {D}_i$) under rigorously qualified operating conditions.
- **The permission path is only as independent as what it shares:** If the permission path shares a clock source, power rail, memory bus, or silicon die with the proposal engine, faults in the proposer can compromise the enforcer. The two-processor split is an architectural hypothesis that requires empirical validation through stress testing and fault injection (**[[01 Books/Volume IV - Physical AI/03 Running the Machine/13 Workload Placement/V4-13.08 Empirical Verification of Silicon Isolation#^sec-placement-testing-separation|Empirical Verification of Silicon Isolation]]**), not an assumed property of separate software processes.
- **The command interface sets what the permission path must check:** Joint position targets express kinematic intent that the enforcer can verify geometrically, but they cannot bound contact forces. Velocity interfaces require a bounded motion projection, while torque interfaces require dynamic bounds and a feasible fallback. Impedance targets bound steady-state interaction forces, but only if the enforcer validates the stiffness and damping gains alongside the reference trajectory.
- **Locate interface regressions at their handoff:** The system handoff record maps every timing and clearance limit to one of five architectural boundaries, binding each to operational preconditions, evidence categories, and bound types. When performance regresses, engineers can isolate the offending subsystem against its allocated budget using like-for-like evidence.

^callout-takeaways--4-2-8a8922fd

Physical stopping limits, inference renewal rates, and the Nervous System’s response delays converge on one governing parameter, how long an admitted proposal may command the actuators. When a timing question arises on a new machine, the first diagnostic is to price that parameter, converting the lease path to distance at the operating speed and comparing it with what the stopping budget has left. A lease that cannot fit between the renewal floor and the pre-brake ceiling cannot sustain uninterrupted proposal tracking at that speed, and a faster processor helps only if it lets the renewal period, and with it the floor, shrink.

This chapter closes Part I, and with it the argument that the first law, irreversibility (principle [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/V4 The Machine Anatomy#^pri-vol4-irreversibility|1]]), set in motion. The Body turned irreversibility into distances and limit records, the Brain into proposals that arrive late and expire, and the Nervous System into a rule of authority. Motion that cannot be undone may be granted only for as long as the stopping budget can still guarantee the stop. The chunk lease is that rule written as a number, and the handoff record is where the number is kept. Everything the machine later learns or is permitted to do inherits this bound, including the demonstrations it collects while the permission path is watching.
