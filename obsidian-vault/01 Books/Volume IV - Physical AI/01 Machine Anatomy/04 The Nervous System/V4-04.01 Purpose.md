*Why must a moving machine keep checking its commands when its learned model stops responding?*

A learned model can pause for a fraction of a second while it interprets a scene, but the machine carrying it keeps moving, and a loaded base covers tens of centimeters in that pause. Every delay between a decision and the current it becomes is therefore paid in clearance. A general-purpose computer hides such delays behind queues, retries, and priorities. A moving machine cannot, because a command that arrives late acts on a body that has already moved, and a check that waits on the model it checks protects nothing once that model stalls. Treating timing and communication as implementation details produces machines whose safeguards share a processor, a supply rail, or a memory bus with the model they guard, and so fail together with it. A machine that acts on learned decisions therefore needs a timed path between proposal and actuator whose delays are bounded, whose checks never wait on the proposer, and whose grant of authority to each proposal expires on its own. At the causal boundary, time granted to a proposal becomes motion that software cannot recall.

**Learning Objectives**

- Explain why the permission path’s independence from the proposer is a requirement to be demonstrated rather than a property of separate processors
- Derive update rates and loop placement from actuator time constants, the phase lag of sampling and transport delay, and proposal renewal limits
- Evaluate mailbox exchanges for bounded reads, complete payloads, and proposal freshness when the writer stalls
- Size a chunk lease between the renewal floor and the pre-brake ceiling, and explain why a host heartbeat cannot renew it
- Distinguish measured latency percentiles from response-time bounds that include computation, blocking, and interference
- Compare position, velocity, torque, and impedance commands by what each leaves the permission path to check
- Evaluate interface timing violations using handoff records that distinguish allocated budgets, supporting evidence, and unresolved bounds
