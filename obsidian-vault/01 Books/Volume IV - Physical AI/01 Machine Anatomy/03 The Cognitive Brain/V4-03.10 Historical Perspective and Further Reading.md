# V4-03.10 Historical Perspective and Further Reading

[[Home|Home]] · [[01 Books/Volume IV - Physical AI/Volume 4 Overview|Volume Overview]] · [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03 The Cognitive Brain|V4-03 The Cognitive Brain]]

^sec-brain-historical-perspective

The two-speed architecture developed throughout this chapter, which couples a slow deliberative proposer with a high-frequency execution loop that continuously services the actuators, is robotics’ recurring answer to a timing constraint. Physical machines have wrestled with this division since Shakey’s deliberative planning ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-nilsson1984shakey|Nilsson 1984]]), Brooks’ reactive subsumption layers ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brooks1986robust|Brooks 1986]]), and ALVINN’s direct learned steering ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-pomerleau1989alvinn|Pomerleau 1989]]). The classical industrial pipelines examined in [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.03 The Classical Wall#^sec-brain-classical-wall|section 3.2]] retained explicit geometric representations by restricting robot operation to structured, calibrated workcells where rigid kinematic models hold, while end-to-end learning gained broad behavioral coverage from data at the cost of formal analytical guarantees.

↩︎ The lineage from Shakey’s deliberative planning through Brooks’ subsumption layers to ALVINN’s learned steering is established in **[[01 Books/Volume IV - Physical AI/00 Introduction/01 The Causal Boundary/V4-01.03 From Prediction to Action#^sec-boundary-prediction-to-action|From Prediction to Action]]**.

The hardware bottlenecks that govern modern policy inference stem from a parallel evolution in computer architecture. Wulf and McKee ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-wulf1995|1995]]) identified the widening memory wall, observing that processor speed was improving far faster than DRAM access time. Williams et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-williams2009roofline|2009]]) formalized this relationship into the roofline model, establishing operational arithmetic intensity, the ratio of floating-point operations performed to memory bytes transferred, as the metric that reveals whether an execution phase is memory-bandwidth-bound or compute-bound. Modern autoregressive models collide directly with these bandwidth ceilings. The Transformer architecture requires every newly generated token to attend over cached keys and values from all preceding context tokens ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-vaswani2017attention|Vaswani et al. 2017]]). As Pope et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-pope2023efficiently|2023]]) demonstrated through analytical modeling of distributed Transformer inference, generating one token at a time splits execution into a compute-bound prompt prefill phase, which processes all input tokens together, and a memory-bandwidth-bound autoregressive decoding phase. In embodied setups, where real-time interactive control requires generating action tokens with a batch size of 1, the memory wall dominates the decode, as notebook [3.1](https://mlsysbook.ai/vol4/03_brain/03_brain.html#nbk-brain-intent-model-latency) prices for the machine and checks against a published measurement on its processor. To alleviate this memory traffic, integer-only quantization demonstrated that low-precision arithmetic could run efficiently on mobile processors with small accuracy loss on the vision networks it evaluated ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-jacob2018quantization|Jacob et al. 2018]]). As the intent-model measurements of [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.05 The Cost of a Fresh Evaluation#^tbl-03-intent-quantization|table 1]] show, however, the cost of a given bit width depends on the method, the kernels, and the task. Modern weight-only formats such as AWQ protect salient weight channels while cutting the bytes transferred across the memory bus on each decoding pass ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-lin2024awq|Lin et al. 2024]]).

Learned proposers emerged when these sequence architectures were adapted to robot sensorimotor trajectories. The Vision Transformer demonstrated that self-attention could replace convolutional feature extractors on raw image patches without losing spatial coherence ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-dosovitskiy2020image|Dosovitskiy et al. 2021]]). RT-1 and RT-2 extended this foundation to robotics by tokenizing continuous physical actions directly into the vocabulary of large vision-language models ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt1|Brohan, Brown, Carbajal, Chebotar, Dabis, et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt2|Brohan, Brown, Carbajal, Chebotar, Chen, et al. 2023]]), while OpenVLA established an open, reproducible seven-billion-parameter architecture that enabled systematic hardware profiling and fine-tuning ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2024openvla|Kim et al. 2024]]). However, evaluating large transformer backbones autoregressively at every single control step proved computationally impractical for low-latency physical loops. Action Chunking with Transformers (ACT) and Diffusion Policy resolved this bottleneck by shifting the unit of prediction from isolated steps to short trajectories ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-zhao2023learning|Zhao et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-chi2024diffusionpolicy|Chi et al. 2025]]), amortizing inference latency over multiple timesteps and reducing the compounding of per-step errors. Advancing this approach, $\pi_0$ coupled a high-capacity vision-language backbone with a flow-matching action expert capable of generating high-frequency motor commands ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-black2024pi0|Black et al. 2024]]). Real-time action chunking hid the inference delay behind execution by freezing the setpoints that run during inference and generating the rest of the next chunk to agree with them ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-black2025realtime|Black, Galliker, et al. 2025]]), a formulation that recasts classical receding-horizon model predictive control through the lens of deep learning ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-mayne2000constrained|Mayne et al. 2000]]). Modern embodied platforms, including Helix ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-figureai2025helix|Figure AI 2025]]) and GR00T N1 ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-bjorck2025gr00t|Bjorck et al. 2025]]), adopt the same two-speed separation. The contract between the two tiers remains an open design question. Deployed systems pass latent vectors, language, or geometry from the slow model to the fast one ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.06 Chunk Supply and Evidence Validity#^tbl-03-state-of-practice|table 2]]). This chapter’s case for a checkable geometric target, together with the invariants a real-time monitor must enforce on it, is one position in that question rather than a settled standard.

Six works trace this lineage from reactive robotics to modern vision-language-action architectures:

- Brooks ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brooks1986robust|1986]]) introduces the subsumption architecture, organizing autonomous robots into layered, asynchronous behaviors that each close their own sensorimotor loop. The paper presents the foundational systems argument that fast reactive loops must never block on deliberative planning, establishing the conceptual basis for modern two-speed execution.
- Williams et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-williams2009roofline|2009]]) introduces the roofline model, a visual bound relating arithmetic intensity to processor compute and memory bandwidth ceilings. The paper provides the standard methodology for diagnosing whether an inference kernel is memory-bound or compute-bound before undertaking hardware optimization.
- Pope et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-pope2023efficiently|2023]]) models Transformer inference from first principles, demonstrating how batch size, sequence length, and tensor partitioning dictate whether execution binds on memory bandwidth or arithmetic execution units. This analysis underpins the performance characterization of batch-size-1 policy inference explored throughout this chapter.
- Zhao et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-zhao2023learning|2023]]) introduces Action Chunking with Transformers (ACT) and temporal ensembling for precise bimanual manipulation. The authors demonstrate that predicting action sequences rather than individual steps dampens compounding tracking errors and stabilizes learned policies, establishing the trajectory chunking approach that real-time learned policies now rely on.
- Chi et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-chi2024diffusionpolicy|2025]]) develops Diffusion Policy, demonstrating why multimodal human demonstrations with multiple valid solutions require expressive generative decoders rather than unimodal regression. The paper explicitly characterizes the systems cost of iterative refinement, quantifying the computational latency required to evaluate multiple diffusion steps per action chunk.
- Kim et al. ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2024openvla|2024]]) provides a complete, open-source seven-billion-parameter vision-language-action model, detailing its training pipeline, data mixture, and deployment trade-offs. The paper includes 4-bit and 8-bit quantization benchmarks, which make it a common reference point for profiling learned embodied policies on edge hardware.

**What’s Next: From learned proposals to the permission path**

A physical machine cannot allow a candidate proposal to continue driving hardware indefinitely when its successor fails to arrive. The mobile manipulator’s chunk policy targets a proposal period of 50 ms, whereas the intent model updates at a slower cadence, and either level can stall, miss its deadline, or misjudge the target object. A check that waits on the proposer it checks stalls along with it. **[[01 Books/Volume IV - Physical AI/01 Machine Anatomy/04 The Nervous System/V4-04 The Nervous System#^sec-nervous|The Nervous System]]** therefore begins with where the permission path must run to stay independent of the learned models. It next derives each tier’s rate from a physical time constant and passes proposals between tiers without letting a slow writer block a fast reader. Only then does it price the chunk lease from the body’s stopping budget and the proposer’s renewal floor, ensuring that an admitted chunk commands the joints for a bounded interval before a deterministic fail-safe response begins.
