# V4-03.04 Learned Representations

[[Home|Home]] · [[01 Books/Volume IV - Physical AI/Volume 4 Overview|Volume Overview]] · [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03 The Cognitive Brain|V4-03 The Cognitive Brain]]

^sec-brain-learned-representations

When commanded to pick an unfamiliar ceramic mug from a conveyor, a learned model relates the text prompt to visual features of the handle and proposes a plausible grasp region without an exact CAD model. VLA models combine multi-camera imagery, natural-language instructions, and proprioceptive robot state to produce candidate actions ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt1|Brohan, Brown, Carbajal, Chebotar, Dabis, et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt2|Brohan, Brown, Carbajal, Chebotar, Chen, et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2024openvla|Kim et al. 2024]]). These systems descend from early embodied language models such as SayCan and PaLM-E, which emitted high-level semantic plans rather than low-level motor commands ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-ahn2022saycan|Ahn et al. 2022]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-driess2023palme|Driess et al. 2023]]). The operational value of a VLA stems from broad generalization across diverse objects and ambient environments acquired during large-scale pretraining, rather than formal guarantees of correct scene interpretation.

Teleoperated demonstrations can likewise teach coordinated sensorimotor policies for tasks whose contacts and structural deformations resist analytic kinematic modeling. In a bimanual teleoperation workcell ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.04 Learned Representations#^fig-aloha-manipulator|figure 5]]), an operator moves low-cost leader arms while follower arms with parallel grippers reproduce the motion, and overhead and wrist cameras record what the followers saw. Those recordings become the training data for policies that later act alone ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-zhao2023learning|Zhao et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-chi2024diffusionpolicy|Chi et al. 2025]]). The running machine’s chunk policy takes its size from ACT, which was trained on exactly such recordings. What such a policy learns from them is the action chunk itself, a short stretch of the operator’s motion predicted from one view. How demonstrations become a policy belongs to **[[01 Books/Volume IV - Physical AI/02 Teaching the Machine/06 Policy Training/V4-06 Policy Training#^sec-training|Policy Training]]**; this chapter prices what the trained policy costs to run. Although learned representations tolerate sensory variations captured across training distributions, executing any proposed motion safely still demands calibrated spatial geometry and strict physical boundary enforcement. Empirical task success demonstrates capability over tested operating envelopes, but out-of-distribution shifts in illumination, surface friction, or payload dynamics can quickly induce behavioral drift or outright failure.

The computational cost of this capability depends directly on the model’s underlying representation. A transformer does not read pixels or words directly; it reads *tokens*, embedding vectors that each represent one slice of input, such as an image patch, a word fragment, or a joint angle. Across a VLA model, that token sequence flows from camera patches and prompt embeddings through self-attention to candidate action chunks ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.04 Learned Representations#^fig-vla-architecture|figure 6]]). Multi-view camera frames consume significant memory bandwidth during ingestion, historical context expands key-value (KV) cache footprints in memory, and the inference engine must produce subsequent actions before the physical state diverges from the initial observation. Evaluating an embodied learned model alongside a classical perception-planning pipeline requires assessing both task generalization and the end-to-end latency required to refresh action proposals.

^fig-vla-architecture

To grasp the mug, the model turns camera images and a language instruction into candidate trajectories in three learned stages: tokenization, attention across the tokens in a backbone, and an action decoder that projects the backbone’s output into proposed motion. A proposal boundary separates all three from actuation, so every candidate action passes independent permission checks before it reaches the motor drives. Evaluating this pipeline from a systems perspective means tracing what each stage stores in memory, transfers across the memory bus, and delivers to the controllers below it:

1.  *Sensory ingestion and spatial tokenization (the inputs).* A vision transformer (ViT) frontend ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-dosovitskiy2020image|Dosovitskiy et al. 2021]]) slices each incoming camera frame into a grid of non-overlapping pixel patches of size ${p_{\text{patch}}}{\times}{p_{\text{patch}}}$ (typically $14{\times}14$ or $16{\times}16$ pixels). Each patch is linearly projected into a vector of width ${d}$, augmented with a position embedding (learned in the SigLIP and DINOv2 encoders that OpenVLA uses ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2024openvla|Kim et al. 2024]]), sinusoidal in some other designs), and tagged with a learned camera identifier.

    In an illustrative three-camera configuration (left wrist, right wrist, and an overhead torso mount) capturing $224{\times}224$ images, the image frontend prepares a buffer for each view. Each frame yields $(224 / 14)^2 =$ 256 spatial patches. Across 3 cameras, ingestion injects 768 visual tokens into the model’s sequence on every perceptual step. When concatenated with tokenized natural language commands (about 32 tokens) and proprioceptive joint state embeddings (about 16 tokens), the initial context runs slightly past 800 tokens, which the estimates below round to ${S} \approx$ 800. In 16-bit floating-point (FP16) precision ($2\,\text{bytes}$ per element) with hidden dimension ${d} =$ 4096, the token embeddings for one such step occupy

$$
M_{\text{embed}} = S \times d \times 2\,\text{bytes} = 800 \times 4096 \times 2 \approx 6.55\,\text{MB}
$$

 a few megabytes, negligible beside the multi-gigabyte weights that [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.05 The Cost of a Fresh Evaluation#^sec-brain-memory-wall|section 3.4.1]] prices. Tokens therefore cost the machine through the arithmetic every weight performs on each of them and through the cache they leave behind, not through the storage of the embeddings themselves. Neither 2D image coordinates nor internal attention patterns constitute metric depth. Projecting an end-effector into physical 3D space requires calibrated extrinsic camera matrices and depth telemetry.

2.  *Multimodal alignment and attention (the backbone).* For the illustrative backbone, the token sequence passes through ${N_L} =$ 32 transformer layers where standard multi-head self-attention computes pairwise token interactions ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-vaswani2017attention|Vaswani et al. 2017]]). To relate each new token to the earlier ones, every layer keeps a *key* and a *value* vector for every token it has already processed, the **KV cache**. The arithmetic of attention grows with the square of the sequence length ($\mathcal{O}({S}^2 {d})$ FLOPs), but the memory the cache occupies grows only linearly with it, as [equation 1](https://mlsysbook.ai/vol4/03_brain/03_brain.html#eq-brain-kv-cache) gives:

$$
{M_{\text{KV}}} = 2 \times {N_L} \times {d} \times {S} \times {s_{\text{elem}}} \tag{1}
$$

 The estimate assumes full-width keys and values, meaning every attention head in every layer stores its own. For a 32-layer model with ${d} =$ 4096 using FP16 storage, each context token then claims 524,288 bytes, about 0.524 MB, of KV cache, so an observation step of several hundred tokens holds hundreds of megabytes.

    ^eq-brain-kv-cache

    Whether the machine pays that charge more than once depends on what the model keeps between evaluations. Single-observation VLAs such as OpenVLA rebuild their context from each new frame and carry no cache across control steps, and the running machine’s intent model is one of them. Only a design that conditions on retained history rereads the cache on every step, and [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.06 Chunk Supply and Evidence Validity#^sec-brain-two-proposers|section 3.5.2]] prices what retaining several seconds of history would cost. Such rereading is not free, because the processor uses a unified memory architecture (UMA), in which the CPU, the GPU, and the camera interfaces share one DRAM. Every byte of cache read is bus time taken from weight streaming and from the direct memory access (DMA) transfers that deliver sensor frames. Grouped-query attention (GQA) narrows the cache by letting several query heads share one key and value; cross-attention can instead limit which retained representations the decoder reads. Either saving depends on the architecture, and action chunking does not provide it.

    Attention weights are also not geometry. A strong weight between the language tokens “mug handle” and a visual patch does not establish a graspable affordance[[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.12 Footnotes#^fn4|⁴]] or collision-free clearance, and the KV cache does not keep track of an object while it is occluded. The formal patch-embedding, position-encoding, and attention formulations appear in **[[05 Reference/Volume IV - Physical AI/V4 Machine Learning Background#^sec-appendix-ml-patch-embedding|Visual patch tokenization, attention, and 3D metric lifting]]**.

3.  *Specialized action decoders (the outputs).* Instead of generating open-ended conversational text, the final hidden representation ${\mathbf{h}_{\text{context}}} \in \mathbb{R}^{d}$ is routed to specialized action decoders. The running machine’s chunk policy proposes base velocity and arm targets together in one whole-body stream ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.06 Chunk Supply and Evidence Validity#^sec-brain-two-proposers|section 3.5.2]]), so its decoder is a manipulation decoder whose outputs include the base. Separate navigation models that decode waypoints over a topological map of the building ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.04 Learned Representations#^fig-vln-navigation|figure 7]]) follow the same proposal rules but are not part of this machine. Manipulation (VLA) models diverge sharply in how they bridge semantic representations to physical motion:

    Discrete action decoders map each action dimension to a categorical token by dividing its continuous range into bins ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt1|Brohan, Brown, Carbajal, Chebotar, Dabis, et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt2|Brohan, Brown, Carbajal, Chebotar, Chen, et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2024openvla|Kim et al. 2024]]). Autoregressive decoders such as RT-2 and OpenVLA then generate those tokens sequentially, requiring one complete model evaluation per action dimension ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt2|Brohan, Brown, Carbajal, Chebotar, Chen, et al. 2023]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2024openvla|Kim et al. 2024]]). However, discretization does not require sequential decoding. RT-1 predicts all action tokens simultaneously in a single forward pass, and its authors demonstrated that autoregressively conditioning each action dimension on preceding dimensions yielded no accuracy gains while more than doubling inference latency ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-brohan2023rt1|Brohan, Brown, Carbajal, Chebotar, Dabis, et al. 2023]]).

    What separates modern decoders in systems practice is the computational cost of generating a trajectory chunk and the volume of model weights reread during inference. Three architectural families dominate implementations as of 2026:

    - *Autoregressive tokens.* Each token requires a separate sequential evaluation. With one token per action dimension per control step, predicting a chunk of ${H}$ timesteps across ${d_a}$ dimensions demands ${H} {d_a}$ sequential evaluations, causing inference latency to scale with both horizon and degree of freedom. Per-step binning also breaks down at high control frequencies: consecutive continuous setpoints differ negligibly, producing runs of identical token targets from which next-token training learns almost nothing. Frequency-space action sequence tokenization (FAST) resolves this scaling bottleneck by applying a discrete cosine transform across each action dimension over the chunk horizon, representing the trajectory as a linear combination of cosine basis functions ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-pertsch2025fast|Pertsch et al. 2025]]). Smooth physical motions concentrate energy in low-frequency coefficients, allowing aggressive truncation. FAST quantizes these coefficients and compresses them with byte-pair encoding, which repeatedly merges the most frequent adjacent pair of symbols into a new token, tying token counts directly to trajectory information complexity rather than ${H} {d_a}$. On a 50 Hz bimanual task, FAST compressed 700 raw binned tokens to 53, achieving a 13.2× reduction ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-pertsch2025fast|Pertsch et al. 2025]]). Token generation nevertheless remains sequential. The authors report an inference latency of approximately 750 ms per chunk for FAST-$\pi_0$, compared to 100 ms for the flow-matching variant on an identical desktop GPU.
    - *One-pass chunk heads.* Action Chunking with Transformers (ACT) regresses an entire trajectory chunk in a single feedforward decoder pass ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-zhao2023learning|Zhao et al. 2023]]). OpenVLA-OFT adapts an autoregressive VLA into a one-pass generator by passing placeholder action tokens through bidirectional self-attention and directly regressing continuous values for all action steps in parallel, increasing throughput by 26× on 8-step chunks ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-kim2025openvlaoft|Kim et al. 2025]]). However, deterministic regression heads trained with mean squared error struggle with multimodal demonstration data: when presented with two equally valid paths around an obstacle, a naive regression loss averages them into an infeasible trajectory directly through the obstacle ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-chi2024diffusionpolicy|Chi et al. 2025]]). **[[01 Books/Volume IV - Physical AI/02 Teaching the Machine/06 Policy Training/V4-06.03 Policy Training Regimes#^sec-training-multimodality-breakdown|Mode averaging when demonstrations split]]** develops this *mode averaging* from the training side. ACT mitigates it by conditioning its decoder on a latent style variable, a code that records which of several demonstrated ways of doing the task a trajectory follows, learned with a conditional variational autoencoder (CVAE, **[[05 Reference/Volume IV - Physical AI/V4 Machine Learning Background#^sec-appendix-ml-multimodal|Mode averaging and the decoders that avoid it]]**).
    - *Iterative action experts.* Diffusion Policy formulates action generation as iterative denoising, starting a candidate chunk from random noise and repeatedly removing the noise a network predicts, adapting continuous diffusion processes originally developed for generative vision models ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-ho2020denoising|Ho et al. 2020]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-chi2024diffusionpolicy|Chi et al. 2025]]). The $\pi_0$ architecture pairs a 300M-parameter flow-matching[[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.12 Footnotes#^fn5|⁵]] **action expert** with a pretrained vision-language model, yielding 3.3B total parameters ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-black2024pi0|Black et al. 2024]]). The large vision-language backbone processes perceptual observations once and caches its key-value activations; the action expert then generates the continuous trajectory chunk across 10 numerical integration steps while attending to that static cache. Each integration step is a forward Euler step. The expert starts the candidate from Gaussian noise, evaluates a learned velocity field that says which direction moves it toward a plausible action chunk, and moves the candidate a small distance that way; after 10 steps the candidate is the chunk. Each step requires a forward pass only through the lightweight action expert and its cross-attention reads into the cached backbone KV activations, avoiding any re-evaluation of the multi-billion-parameter vision-language backbone. Subsequent designs such as $\pi_{0.5}$ and GR00T N1 employ this exact decoupling ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-black2025pi05|Black, Brown, et al. 2025]]; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-bjorck2025gr00t|Bjorck et al. 2025]]), with $\pi_{0.5}$ combining FAST-token pretraining on the backbone with flow-expert execution at runtime.

    Across all three families, the continuous output forms a multi-step trajectory chunk:

$$
{\mathbf{A}_{t:t+H-1}} = [{\mathbf{a}}_{t}, {\mathbf{a}}_{t+1}, \dots, {\mathbf{a}}_{t+{H}-1}] \in \mathbb{R}^{{H} \times {d_a}}
$$

 Here ${H}$ specifies the future prediction horizon in discrete setpoints and ${d_a}$ denotes the degrees of freedom per action; [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.06 Chunk Supply and Evidence Validity#^sec-brain-action-chunking|section 3.5.1]] states the formal definition ([3.2](https://mlsysbook.ai/vol4/03_brain/03_brain.html#dfn-brain-action-chunking)) once the memory wall has shown why chunks are needed. Published horizons span from tens to hundreds of setpoints: Diffusion Policy predicts 16 steps and executes the initial 8 ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-chi2024diffusionpolicy|Chi et al. 2025]]), $\pi_0$ predicts 50 steps ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-black2024pi0|Black et al. 2024]]), and ACT predicts 100 steps at 50 Hz ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-zhao2023learning|Zhao et al. 2023]]). The structural gap between prediction and execution horizons resurfaces in [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.06 Chunk Supply and Evidence Validity#^sec-brain-two-proposers|section 3.5.2]] as the interface between asynchronous trajectory generation and real-time permission filtering. A trajectory chunk provides an open-loop sequence of future setpoints derived from a single sensory context, amortizing inference latency without incorporating intervening sensor observations. [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.06 Chunk Supply and Evidence Validity#^sec-brain-action-chunking|Section 3.5.1]] evaluates the computational efficiency of these three decoder families on target silicon, while **[[05 Reference/Volume IV - Physical AI/V4 Machine Learning Background#^sec-appendix-ml-multimodal|Mode averaging and the decoders that avoid it]]** gives the discrete tokenization rule and details how generative decoders capture multimodal demonstration distributions without averaging conflicting trajectories.

4.  *The proposal boundary (isolation from actuators).* Whether the model plans navigation or manipulation, its output is an unprivileged candidate proposal strictly outside the proposal boundary (definition [1.3](https://mlsysbook.ai/vol4/01_boundary/01_boundary.html#dfn-boundary-proposal-boundary)). Under the concrete machine model established in **[[01 Books/Volume IV - Physical AI/00 Introduction/01 The Causal Boundary/V4-01.08 The Machine in Five Levels#^sec-boundary-machine-model|The Machine in Five Levels]]**, the foundation model runs in unprivileged user space on the host application processor and has no direct memory-mapped access to pulse-width modulation (PWM) registers or motor coil current drivers. Instead, the Brain hands candidate motion, stamped with the capture times of the sensory frames that generated it, to a permission path whose kilohertz loops a slow inference cannot preempt or bypass. That path refuses proposals that would collide, violate joint limits, or drive the arm into a kinematic singularity (an arm configuration in which the joints lose the ability to move the end effector in some direction). **[[01 Books/Volume IV - Physical AI/01 Machine Anatomy/04 The Nervous System/V4-04.07 Actuation Authority#^sec-nervous-actuation-authority|Actuation Authority]]** isolates this gating logic on a dedicated real-time safety microcontroller, completely segregated from the application processor hosting the learned model.

^fig-vln-navigation

The choice of sensory representation and action decoder dictates the memory traffic and latency profile of every control cycle. Maintaining historical token context accumulates KV cache overhead that consumes memory bus bandwidth, while running multi-billion-parameter backbones on resource-constrained embedded systems demands heavy weight streaming from off-chip DRAM. An embodied agent needs both semantic breadth and rapid trajectory renewal, and these costs suggest that one monolithic model on an embedded processor cannot deliver both. Whether it can is a question of numbers, and the place to get them is one fresh evaluation of the machine’s intent model on its own application processor.
