# V4-03.12 Footnotes

[[Home|Home]] · [[01 Books/Volume IV - Physical AI/Volume 4 Overview|Volume Overview]] · [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03 The Cognitive Brain|V4-03 The Cognitive Brain]]

^footnotes

<sup>1</sup> **End-Effector**: The tool, gripper, or hand at the distal tip of a manipulator, the only part of the arm meant to touch the workpiece. Workspace and keep-out checks are written against its pose rather than against joint angles, which is why the proposal payload later in this chapter carries end-effector poses alongside joint targets.

^fn1

<sup>2</sup> **Manipulator Equation**: Classical control computes joint torques from ${\mathbf{M}}({\mathbf{q}}){\ddot{\mathbf{q}}} + {\mathbf{C}}({\mathbf{q}}, {\dot{\mathbf{q}}}){\dot{\mathbf{q}}} + {\mathbf{g}}({\mathbf{q}}) = {\boldsymbol{\tau}}$, with a configuration-dependent inertia matrix ${\mathbf{M}}$, Coriolis and centripetal terms ${\mathbf{C}}$, and gravity ${\mathbf{g}}$. Torque is linear in inertia, and a link’s inertia grows with the square of its distance from the joint, so an outstretched arm needs more torque for the same angular acceleration. Unmodeled contact, friction, or deformable objects break this rigid-body model, which is the gap learned proposers enter; **[[05 Reference/Volume IV - Physical AI/V4 Control and Dynamics#^sec-appendix-control-feedback-lin|Feedback linearization: Transforming nonlinear dynamics into decoupled double integrators]]** shows how classical control inverts this model to compute torque.

^fn2

<sup>3</sup> **Lyapunov Stability**: Aleksandr Lyapunov’s 1892 method establishes stability near an equilibrium using a positive-definite, energy-like function whose derivative along the modeled dynamics is nonpositive; asymptotic convergence requires stronger decrease or invariance conditions ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-slotine1991applied|Slotine and Li 1991]]). Applying the method requires a justified closed-loop dynamics model and verified certificate conditions; a learned proposer does not acquire such a certificate merely from training. The barrier certificates of **[[01 Books/Volume IV - Physical AI/03 Running the Machine/12 Safety Enforcement/V4-12.06 Safe Sets as Conditional Permission#^sec-enforcement-safe-sets-conditional-permission|Safe Sets as Conditional Permission]]** reuse the idea to keep the machine inside a safe set rather than at a point.

^fn3

<sup>4</sup> **Affordance**: Gibson’s term for the action possibilities an environment offers an agent, defined jointly by object properties and agent physical capabilities ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-gibson1979ecological|Gibson 1979]]). A handle affords a grasp only when its physical dimensions and clearance accommodate the robot’s gripper geometry and kinematics. While self-attention weights across image patches highlight semantically relevant features such as a handle, they do not certify mechanical grasp stability or kinematic reachability, the failure mode [[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.07 Cognitive Vulnerabilities#^sec-brain-semantic-hallucinations|section 3.6.1]] analyzes.

^fn4

<sup>5</sup> **Flow Matching**: A method that trains a neural network to predict a continuous velocity field carrying samples from Gaussian noise to the target data distribution along nearly straight paths ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-lipman2022flow|Lipman et al. 2022]]). Because those paths are straight, numerical solvers can generate samples in a handful of Euler steps, whereas older denoising diffusion models needed hundreds of sequential steps ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-ho2020denoising|Ho et al. 2020]]). On an embedded robot processor, the step count directly sets latency because each solver step rereads the action expert’s weights and cached visual context from off-chip memory.

^fn5

<sup>6</sup> **SE(3) Pose**: SE(3), the special Euclidean group in three dimensions, is the set of rigid-body poses, a rotation plus a translation with six degrees of freedom; “special” excludes mirror reflections, which no rigid object can undergo. A pose can be compared with measured depth and aged from its capture time, while a semantic label such as “mug handle” can be neither, which is why the handoff to planning is a pose and not a label.

^fn6

<sup>7</sup> **Wulf and McKee**: Their short paper named the memory wall ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-wulf1995|Wulf and McKee 1995]]), observing that processor speed was improving far faster than DRAM latency, so that memory access would eventually dominate run time whatever the processor did. Caches postponed the wall for workloads that reuse their data, but a batch-1 model on a robot meets it directly. When each weight is used once per fetch, the bus, not the arithmetic, sets how often a fresh proposal can arrive.

^fn7

<sup>8</sup> **Receding Horizon**: Model predictive control optimizes over a fixed horizon, executes only the first part of the plan, and then replans from the newly measured state, so the horizon recedes as time advances ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-mayne2000constrained|Mayne et al. 2000]]). A chunked policy is the learned analog and inherits the same rule: the unexecuted tail of a chunk is a buffer that the next evaluation may overwrite, never a commitment the machine owes to finish.

^fn8

<sup>9</sup> **Lipschitz Continuity in Neural Policies**: Although neural networks with smooth activations are continuous on compact domains, a sensitivity bound ${L_{\text{lip}}} = \sup_{{\mathbf{x}}_1 \ne {\mathbf{x}}_2} \frac{\lVert \pi({\mathbf{x}}_1) - \pi({\mathbf{x}}_2) \rVert}{\lVert {\mathbf{x}}_1 - {\mathbf{x}}_2 \rVert}$ must be established over a stated operating region. Where that bound holds, sensor error $\lVert {\Delta} {\mathbf{x}} \rVert \le {\epsilon}$ bounds the action change by $\lVert {\Delta} {\mathbf{a}} \rVert \le {L_{\text{lip}}}{\epsilon}$; an unverified ${L_{\text{lip}}}$ gives no usable action-error guarantee. Full derivations appear in **[[05 Reference/Volume IV - Physical AI/V4 Machine Learning Background#^sec-appendix-ml-lipschitz|Lipschitz continuity and spectral normalization]]**.

^fn9

<sup>10</sup> **Softmax** (soft arg max): Bridle ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-bridle1990probabilistic|1990]]) named the normalized exponential “softmax” because it is a differentiable version of the winner-take-all operation that picks the largest input. A function built to pick a winner keeps doing so far from its training data, pushing its top output toward one whenever one logit separates from the rest, whether or not the input resembles anything the model has seen.

^fn10

<sup>11</sup> **Exchangeability**: The conformal guarantee assumes only that the calibration trials and the new trial are exchangeable, a weaker condition than independent and identically distributed data ([[01 Books/Volume IV - Physical AI/01 Machine Anatomy/03 The Cognitive Brain/V4-03.11 Source References#^ref-vovk2005algorithmic|Vovk et al. 2005]]). A deployed robot can break even that weaker assumption because its actions change the scenes it meets next, the endogenous data of the second law (**[[01 Books/Volume IV - Physical AI/00 Introduction/01 The Causal Boundary/V4-01.11 The Four Bedrock Laws#^sec-boundary-bedrock-laws|The Four Bedrock Laws]]**). A threshold calibrated under one policy therefore has to be re-established after every policy or deployment change, and its stated coverage lapses in between.

^fn11

<sup>12</sup> **Debouncing**: The contacts of a mechanical switch bounce for milliseconds when pressed, so embedded firmware accepts a new switch state only after it has persisted for a set interval. The same ${N}$-frame rule applied to class labels suppresses chattering, but it delays every genuine change by ${N}$ frames, time charged to the observation-age budget before any proposal is renewed.

^fn12
