# V3-13.09 Historical Perspective and Further Reading

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13 Agent Evaluation|V3-13 Agent Evaluation]]

^sec-vol3-evaluation-history

The statistical foundations of agent evaluation predate electronic computing, emerging from industrial quality control and experimental design. Wilson derived the score interval in 1927 to bound binomial success probabilities reliably even in small sample regimes where normal approximations fail ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-wilson1927probable|Wilson 1927]]). Two decades later, McNemar formulated his matched-pairs test to compare binary outcomes across identical subjects, establishing a rigorous basis for head-to-head model comparisons on fixed benchmark sets without assuming treatment independence ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-mcnemar1947note|McNemar 1947]]). For qualitative metrics, Cohen introduced ${\kappa}$ to quantify inter-annotator agreement beyond chance ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-cohen1960|Cohen 1960]]), while Efron later introduced the non-parametric bootstrap to estimate sampling variance and confidence intervals for arbitrary statistics lacking closed-form analytical distributions ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-efron1979bootstrap|Efron 1979]]). In 2001, Brown, Cai, and DasGupta demonstrated that the standard Wald interval oscillates erratically in coverage and systematically fails near boundary proportions, even at sample sizes of several hundred. For that reason, this chapter adopts Wilson’s score interval as the engineering default for small-sample agent evaluation suites ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-brown2001interval|Brown et al. 2001]]).

Evaluation methodologies in machine learning arrived at these same conclusions through hard-won practical failures. Dwork et al. ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-dwork2015reusable|2015]]) demonstrated that iteratively consulting a held-out evaluation dataset to guide modeling decisions leaks information and causes adaptive overfitting, establishing formal bounds through differential privacy to preserve dataset reuse. Shortly thereafter, Recht et al. ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-recht2019imagenet|2019]]) collected new, independent test sets for ImageNet and observed pervasive accuracy degradation across leading architectures, attributing the drops to subtle shifts between the original and replicated test distributions rather than to adaptive overfitting of the original benchmark. Together, these findings demonstrate why sound evaluation protocols must separate fast development feedback from strictly quarantined held-out benchmarks, while precisely characterizing the underlying task population.

As systems shifted toward autonomous execution, static classification metrics yielded to dynamic task validation. In code synthesis, Chen et al. ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-chen2021evaluating|2021]]) introduced the pass@${k}$ metric alongside an unbiased, low-variance estimator to measure execution correctness across multi-sample generation budgets. When automated foundation models were enlisted as evaluators, Zheng et al. ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-zheng2023judging|2023]]) measured the biases of model-based judges, reporting position and verbosity preferences while finding the evidence for self-enhancement bias inconclusive. Benchmark design subsequently evolved from conversational question-answering to interactive, stateful sandbox environments: SWE-bench evaluated software engineering agents against verified test suites on real GitHub issues ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-jimenez2024swebench|Jimenez et al. 2024]]), and WebArena placed web agents in live, multi-service environments evaluated on final system states ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-zhou2024webarena|Zhou et al. 2024]]). Finally, recognizing that single trajectory outcomes conceal non-deterministic variance, Yao et al. ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-yao2024taubench|2024]]) introduced Tau-bench to measure agent consistency across repeated trials, while Kapoor et al. ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-kapoor2024agents|2024]]) demonstrated that rigorous agent comparisons require benchmarking cost and resource consumption alongside accuracy along empirical Pareto frontiers.

**Further reading.**

- **Brown, Cai, and DasGupta, “Interval Estimation for a Binomial Proportion”** ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-brown2001interval|Brown et al. 2001]]): An empirical and theoretical analysis demonstrating why the standard Wald interval breaks down across small samples and boundary probabilities, establishing the superiority of the Wilson score interval for agent evaluation suites.
- **Dwork et al., “The Reusable Holdout”** ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-dwork2015reusable|Dwork et al. 2015]]): A concise, rigorous treatment explaining how iterative evaluation on a test set degrades its statistical validity through adaptive overfitting, introducing differential privacy mechanisms for sound reuse.
- **Zheng et al., “Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena”** ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-zheng2023judging|Zheng et al. 2023]]): A systematic measurement of model-based judges against human preferences, reporting position and verbosity biases, and the starting point for calibrating a judge before it grades acceptance.
- **Kapoor et al., “AI Agents That Matter”** ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-kapoor2024agents|Kapoor et al. 2024]]): A case study in agent benchmark methodology, advocating for reporting inference costs and resource consumption alongside success rates along empirical Pareto frontiers.
