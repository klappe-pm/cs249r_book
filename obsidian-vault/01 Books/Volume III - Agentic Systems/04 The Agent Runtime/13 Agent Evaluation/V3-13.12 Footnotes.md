# V3-13.12 Footnotes

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13 Agent Evaluation|V3-13 Agent Evaluation]]

^footnotes

<sup>1</sup> **Goodhart’s Law and the Held-Out Suite**: The selection pressure that breaks an imperfect check during search (**[[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.05 Verifying Candidates#^sec-vol3-test-time-compute-selection-pressure|How search exploits imperfect checks]]**) acts on an evaluation suite in the same way. A held-out suite used to choose among prompts has become a control target, so its score drifts from measuring the task population toward measuring fit to the suite. The simplest remedy is procedural. Retire a suite into development use once it has steered decisions, and hold a fresh one for the release claim.

^fn1

<sup>2</sup> **Wald Interval Coverage**: A systematic study of binomial intervals found that the Wald interval’s actual coverage oscillates erratically with both ${N}$ and ${p_{\text{acc}}}$, stays poor at sample sizes that textbook rules of thumb call safe, and recommended the Wilson interval for small samples ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-brown2001interval|Brown et al. 2001]]). Agent evaluation lives in exactly that regime: suites of tens of tasks, and violation rates near zero, where a nominal 95 percent Wald interval can promise far more than it delivers.

^fn2

<sup>3</sup> **Wilson score inversion**: At two-sided confidence level $1-{\alpha_{\text{sig}}}$, the score interval contains the values ${p_{\text{acc}}}\in[0,1]$ satisfying ${N}({\hat{p}}-{p_{\text{acc}}})^2\le {z_{\alpha/2}}^2{p_{\text{acc}}}(1-{p_{\text{acc}}})$. Solving this quadratic inequality gives the endpoints: the variance uses the hypothesized ${p_{\text{acc}}}$, rather than fixing it at ${\hat{p}}$ as in the Wald construction ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-guthrie2020nisthandbook|Guthrie 2020, sec. 7.2.4.1]]).

^fn3

<sup>4</sup> **McNemar’s Test**: The test was introduced for psychological measurements in which the same subjects are classified twice, so the two proportions are correlated and cannot be compared as independent samples. Its central move is to discard concordant pairs from the test statistic, since a task both configurations pass, or both fail, says nothing about which is better. The interval for ${\Delta}$ still uses those pairs, because they set the precision of the estimate.

^fn4

<sup>5</sup> **Consistency on a Live Benchmark**: At the benchmark’s 2024 introduction, its authors reported that the strongest function-calling agent they tested completed fewer than 50 percent of tasks, and that its pass$^{k}$ at ${k}$ equal to 8 fell below 25 percent in the retail domain ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.11 Source References#^ref-yao2024taubench|Yao et al. 2024]]). The specific agents will age; the pattern will not, because consistency over repeated sessions always sits below single-run success once any task passes with probability below one.

^fn5
