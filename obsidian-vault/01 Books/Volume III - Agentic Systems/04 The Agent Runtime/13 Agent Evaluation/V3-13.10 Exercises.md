# V3-13.10 Exercises

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13 Agent Evaluation|V3-13 Agent Evaluation]]

^sec-vol3-13-evaluation-exercises-5fd17744

Each problem states its constraints and ends in a decision about what the evidence supports or what to collect next. Givens are hypothetical unless a lighthouse profile supplies them, and every interval is a nominal 95 percent interval with ${z}=1.96$.

**1. New tasks or repeats (Basic).** A pilot of the repair agent’s evaluation suite estimates a mean task acceptance probability of 0.6 and a between-task variance ${\sigma_{\text{task}}}^2=0.08$. (a) Derive ${\sigma_{\text{run}}}^2$ from these two givens using its definition in [[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.06 Statistical Evaluation Rigor#^eq-variance-decomposition|equation 1]], and find the number of runs per task beyond which the run term of the variance falls below the task term. (b) With a budget of 600 graded runs, and new tasks available at no extra cost, compare the standard error of ${\hat{p}}$ for 600 tasks run once, 200 tasks run 3 times, and 100 tasks run 6 times, and choose a design. (c) Writing and validating a new hermetic fixture in fact costs as much as 10 graded runs. Within the same budget of 600 run-equivalents, find the runs per task ${R}$, each with the largest whole task count ${N}$ it affords, that minimizes $\operatorname{Var}({\hat{p}})$. Explain why the best design moved, and state which population the resulting estimate describes.

**2. A clean record on the replica (Basic).** The remediation agent runs a candidate configuration on an isolated replica for 60 independently sampled incident tasks, and state-delta checks find no wrong change in any of them. From the lighthouse profile, a wrong change that commits costs \$12,000, and the human approval that currently gates every change costs \$20 of reviewer time. (a) Compute the Wald and Wilson intervals for the wrong-change rate, and state which one a release record can use. (b) Ignoring any later canary check, price the Wilson upper limit as an expected loss per task and compare it with the approval cost. (c) Find how many consecutive clean replica tasks would bring that expected-loss bound below the approval cost. Decide whether the 60 clean runs justify removing human approval, and name the class of evidence that no count of replica runs can supply.

**3. Agreement is not accuracy (Basic).** Two model judges, A and B, score 200 research-agent reports under the same versioned rubric. Both pass 110 reports, A passes and B fails 10, A fails and B passes 20, and both fail 60. An independent reference assessment of the same reports finds 80 failures, of which B accepted 16, and 120 passing reports, of which B accepted 114. (a) Compute the raw agreement and Cohen’s ${\kappa}$ between the judges. (b) Compute B’s false-acceptance rate $\Pr(\text{Acc}\mid {F})$ with its Wilson interval, and the failure fraction among B’s acceptances, $\Pr({F}\mid\text{Acc})$. (c) The release policy admits a judge as an acceptance grader only if the Wilson upper limit on its false-acceptance rate is at most 10 percent. Decide whether B qualifies, and state what a random audit of B-accepted reports alone could and could not establish.

**4. Paired evidence for the offline gate (Intermediate).** A repair-agent comparison runs one baseline and one candidate trial on each of 200 independently sampled tasks, with complete verdicts: both accepted on 120 tasks, only the baseline on ${b}=6$, only the candidate on ${c}=16$, and neither on 58. The declared tolerance is ${\delta_{\text{tol}}}=2$ percentage points. (a) Compute ${\hat{\Delta}}$, the discordant fraction ${\psi}$, and a normal-approximation paired interval from the variance $({\psi}-{\Delta}^2)/{N}$. Decide whether the candidate is noninferior and whether it is superior. (b) Compute each configuration’s separate Wilson interval, and show what a team that required non-overlapping intervals would have decided. (c) Compute the ratio of independent-arm variance to paired variance at these acceptance rates, and the number of tasks per independent arm that would match the paired precision. (d) Compute the exact two-sided McNemar value. Explain how it can sit just above 0.05 while the paired interval excludes zero, and state which result the declared gate uses.

**5. Choose the generator, not the cap (Intermediate).** The repair agent selects sequentially, stopping at the first candidate that passes an exact checker costing ${v}=\$0.04$ per candidate. Generator A passes with ${p_{\text{acc}}}=0.3$ at ${g}=\$0.05$ per candidate; generator B passes with ${p_{\text{acc}}}=0.5$ at ${g}=\$0.12$. (a) Compute ${C_{\text{eff,seq}}}$ for each generator. (b) The task deadline allows at most 4 sequential candidates, and the contract requires availability ${q}_k\ge 0.90$ within that cap. Determine which generator meets it, and the smallest cap generator A would need. (c) A teammate proposes generator A with all candidates generated and checked in parallel at the cap from (b) so that the deadline holds. Compute ${C_{\text{eff,batch}}}$ for that design and compare it with generator B under sequential selection. (d) The team replaces the checker with the full regression suite at ${v}=\$0.20$. Recompute both sequential costs, find the checking cost at which the two generators tie, and state the design rule the crossover illustrates.

**6. Second lighthouse: the support agent’s consistency (Intermediate).** The support agent answers a refund-policy question correctly on 85 percent of single runs, and the same customer asks it in 5 separate sessions. A wrong answer that a customer has read cannot be retried, and a human handoff costs \$4 per session. (a) Compute pass$^{k}$ over the 5 sessions, the single-run rate that would hold 90 percent consistency, and the factor by which the single-run failure rate must fall. For contrast, compute pass@$3$ at the same single-run rate, the quantity a repair agent with a checker in the loop could use. (b) A policy-grounded model judge now screens each answer before delivery, with ${\epsilon_{\text{FA}}}=0.20$ and ${\epsilon_{\text{FR}}}=0.05$, and every rejected answer goes to a human handoff. Per session, compute the probability that a wrong answer reaches the customer, the handoff probability, and the expected handoff cost; then compute the probability that all 5 sessions deliver no wrong answer. (c) Find the largest ${\epsilon_{\text{FA}}}$ that holds 90 percent over the 5 sessions, and the expected handoff cost per session at that rate. (d) Contrast the constraint that binds this agent’s evaluation claim with the one that binds the repair agent’s, and state which grader measurement the support agent’s release record must therefore carry.

**What’s Next: From offline evidence to live operation**

An offline comparison ends with a verdict about a configuration on a sampled task population, and for `candidate_v2` that verdict is inconclusive. It cannot say why a particular trial failed, and it says nothing about what the configuration does once it acts on live work with real authority. **[[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14 Operating Agents#^sec-vol3-operations|Operating Agents]]** follows the connection-pool repair past this point: traces bind each model call, tool execution, and check to its trial, while verdict-aware retention keeps rare failures within storage and privacy budgets. Controlled postmortems then test an explanation by intervening on the recorded trajectory, and staged releases bound what an undetected regression can do before a declared gate decides.
