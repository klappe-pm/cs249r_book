# V3-14.02 From Offline Verdict to Live Operation

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14 Operating Agents|V3-14 Operating Agents]]

^sec-vol3-operations-introduction

The offline comparison of `candidate_v2` against `baseline_v1` ended without a decision in either direction. The candidate accepted more of the paired tasks, but its paired interval does not exclude a loss larger than the declared tolerance, and a powered follow-up sample is still to be planned. That verdict concerns a configuration on a sampled task population. It says nothing about why a particular trial failed, and nothing about what the configuration does once it acts on live work, where inputs are not fixtures, dependencies are shared, and every admitted task exercises real authority.

↩︎ The paired comparison that leaves `candidate_v2` inconclusive against its noninferiority margin is established in **[[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/13 Agent Evaluation/V3-13.06 Statistical Evaluation Rigor#^sec-vol3-evaluation-paired|Paired outcome comparison]]**.

![[90 Assets/Volume III/13 Evaluation/Hsa Locator Hsa 18ba12f601.svg]]

*H·S·A locator with all three axes, Horizon, State, and Authority, highlighted.*

*Operating a configuration carries every exposure at once: the state a failure leaves, the horizon before a monitor decides, and the authority a rollback cannot recall.*

The repair agent (**[[01 Books/Volume III - Agentic Systems/00 Introduction/01 Introduction/V3-01.05 The H·S·A Exposure Space#^sec-vol3-intro-lighthouses|Four lighthouse workloads]]**) supplies this chapter’s case. One trial of `candidate_v2` on the connection-pool repair fails after its search tool returns a silently truncated result, and the next model response proposes rewriting a file outside the permitted repair scope, which the runtime refuses before dispatch. Aggregate counts record the failure; they cannot say whether the model, the observation adapter, a slow dependency, or the runtime is responsible, or whether repairing one of them would change the outcome. Answering those questions takes evidence the offline harness never collected, gathered while the system runs and kept long enough to inspect.

Four kinds of operational evidence fill that gap, and each has its own limits. A trace binds every model call, tool execution, and check to its trial, so that a delay or a failure can be attributed along the trajectory’s critical path ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14.03 Distributed Trajectory Tracing#^sec-vol3-evaluation-tracing|section 14.2]]). Retention policy decides which traces survive storage and privacy budgets, and the accounting record keeps the evaluation denominator complete when diagnostic detail is sampled ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14.04 Trace Retention and Privacy#^sec-vol3-evaluation-budgets|section 14.3]]). An incident postmortem turns an observed mismatch into a hypothesis and tests it by intervening on a saved prefix of the recorded trajectory, since no amount of rereading historical telemetry can answer a counterfactual ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14.05 Incident Postmortems#^sec-vol3-evaluation-postmortems|section 14.4]]). Staged release then exposes a revised configuration to live work only as fast as sequential evidence and hard tripwires allow, because a rollback stops new admission but settles nothing already done ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14.06 Staged Releases#^sec-vol3-evaluation-releases|section 14.5]]). The chapter closes by joining these records with the offline comparison into one decision record and a declared release rule ([[01 Books/Volume III - Agentic Systems/04 The Agent Runtime/14 Operating Agents/V3-14.07 The Release Decision#^sec-vol3-evaluation-synthesis|section 14.6]]), beginning with the trace that explains where the truncated-observation trial spent its time.
