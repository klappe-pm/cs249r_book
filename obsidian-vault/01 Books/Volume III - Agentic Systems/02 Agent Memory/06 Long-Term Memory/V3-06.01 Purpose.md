*Why does an agent that can search everything it has ever stored still act on the wrong facts?*

A context window holds the working state of one model call, and retained attention state only accelerates computation over that same prefix. Neither decides what an agent should still know across sessions, system restarts, or extended operational horizons. Providing an agent with persistent memory requires an external storage architecture that can index varied experiences, retrieve relevant historical context without polluting active prompts, and resolve conflicting observations over time. However, semantic vector retrieval alone provides no temporal guarantees. Stale facts, superseded code versions, and contradicted preferences score just as highly in cosine similarity as fresh ground truth. The runtime must therefore treat every stored memory as a fallible claim that carries its provenance, the versions for which it holds, and an explicit path to invalidation. Reliability depends on keeping persistent state behind explicit consistency rules rather than trusting the model to reconcile contradictory historical evidence.

**Learning Objectives**

- Classify persistent records by their source, evidential role, and relationship to derived search representations
- Specify a retrieval contract that bounds access, returned content, resource use, and required freshness
- Choose among pre-staged evidence, a direct read, and model-directed search from how much of the need the task names
- Select retrieval methods for an information need, use a bandwidth floor to screen exact vector scans against a latency budget, and estimate multi-hop evidence against a serialized-token budget
- Design a memory write policy for admission, correction, supersession, expiry, and deletion that keeps derived summaries from perpetuating a withdrawn claim
- Explain version-aware exclusion and fallback without mistaking removal of stale candidates for complete fresh retrieval
- Evaluate cross-session memory policies by task outcomes, update behavior, and total resource cost
