# V3-05.11 Summary

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05 KV Cache Management|V3-05 KV Cache Management]]

^sec-vol3-kv-cache-summary

Retained key-value (KV) attention state is a cache of intermediate computation. Like any cache, its cost has two parts, capacity and residency. Capacity is the bytes it occupies in high-bandwidth memory, which grow with the model’s tensor geometry and the active sequence length. Allocation decides how many of those bytes do useful work, since coarse blocks strand bytes in internal fragmentation and branches that do not share a common prefix store it twice. Residency is how long a sequence holds those bytes. It is what turns capacity into throughput, because an agent blocked on a tool call still occupies accelerator memory, and every byte it holds is a byte another request cannot use. Every memory management policy examined in this chapter (paged block tables, tree-based prefix eviction, offloading, and recomputation) trades memory footprint against recomputation work and scheduling delay. Cache mechanisms manage physical storage, but they cannot assess whether cached tokens remain semantically valid; context validity stays the responsibility of the agent harness and the context it supplies. **Key Takeaways: Managing derived attention state**

- **Retained length is the capacity knob**: With model weights occupying a static allocation, resident capacity scales inversely with retained sequence length, falling from 195 sequences at 8,192 tokens down to 12 sequences at 131,072 tokens on the reference node. A context length that easily satisfies the model architecture’s maximum context window can still quickly exhaust the serving node’s physical memory pool.
- **Physical blocks, not logical references, consume capacity**: Paged attention rounds private sequence state up to fixed-size blocks, whereas identical prefix sequences share physical blocks through reference counting. Reclaiming a finished trajectory frees only those physical blocks whose reference count drops to zero, ensuring active sequences and asynchronous transfer operations remain protected.
- **Prefix reuse requires both structural compatibility and memory availability**: Matching token prefixes permit KV cache reuse only when the corresponding physical blocks remain resident and accessible under tenant-isolation rules. A cache hit guarantees neither the freshness of underlying external data nor the semantic validity of the trajectory; preserving cache affinity must never prevent an agent harness from invalidating stale context.
- **Retention policies and compute schedulers manage complementary resources**: Chunked prefill schedules incoming prompt tokens alongside active decodes to prevent high latency spikes during token generation. Similarly, each way of handling a paused agent trajectory (retaining its blocks in accelerator memory, offloading them to host RAM or secondary storage, or recomputing them on demand) exchanges memory footprint for interconnect bandwidth and resumption latency. The optimal strategy depends on the link bandwidth and the expected wait duration.
- **Idle tool waits impose a severe residency tax on throughput**: Static resident-fit bounds govern instantaneous occupancy rather than sustained request throughput. Holding physical cache blocks resident while an agent waits on external tools or human feedback depresses sustainable turn throughput by the residency tax factor $1 + {T_{\text{tool}}}/{T_{\text{model}}}$. Production admission and eviction policies must therefore optimize for end-to-end task completion rates and tail latency rather than raw accelerator memory utilization.

^callout-takeaways--5-2-98d534a9

Attention state derived from the token prefix (principle [[01 Books/Volume III - Agentic Systems/02 Agent Memory/V3 Agent Memory Principles#^pri-vol3-prefix-coherence|5]]) enables the serving engine to reuse previous computation rather than evaluating redundant prompt tokens. Precise block tracking and residency accounting quantify the trade-off between retaining that state and freeing high-bandwidth memory for active generation. Throughout these optimizations, authority stays with the source (principle [[01 Books/Volume III - Agentic Systems/02 Agent Memory/V3 Agent Memory Principles#^pri-vol3-source-authority|6]]): an inexpensive continuation never justifies serving an obsolete observation when the underlying system or environment has changed.
