# V3-05.12 Historical Perspective and Further Reading

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05 KV Cache Management|V3-05 KV Cache Management]]

^sec-vol3-kv-cache-history

Almost every memory management technique in this chapter resolves an architectural problem that time-sharing operating systems encountered decades ago. When early programs outgrew physical core memory, the Manchester Atlas one-level store introduced paging ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-kilburn1962onelevel|Kilburn et al. 1962]]). An address translation table mapped a program’s contiguous virtual address space onto scattered physical page frames, freeing programmers from managing manual overlays and allowing memory to allocate without contiguous physical reservations. Decoupling virtual addresses from physical layout promptly exposed new systems trade-offs. Randell ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-randell1969fragmentation|1969]]) formalized the distinction between internal fragmentation (storage lost inside rounded-up allocations) and external fragmentation, where free memory sits stranded between allocations. Belady ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-belady1966study|1966]]) demonstrated that optimal offline page replacement requires clairvoyant knowledge of future memory references, establishing that practical online policies must rely on heuristics. When memory pressure mounted, time-sharing systems routinely collapsed into thrashing, spending virtually all cycles swapping pages rather than executing user code. Denning’s working-set model clarified the dynamics of this failure and proved that the only dependable remedy was admission control. That meant admitting fewer concurrent processes rather than swapping pages more aggressively ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-denning1968|Denning 1968a]], [[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-denning1968thrashing|1968b]]). Operating systems also pioneered fine-grained memory sharing. The TENEX system introduced copy-on-write sharing so that multiple processes could reference identical pages safely until one attempted a mutation ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-bobrow1972tenex|Bobrow et al. 1972]]), while Morrison’s PATRICIA trees indexed strings through shared prefixes ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-morrison1968patricia|Morrison 1968]]). Denning ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-denning1970|1970]]) gathered these foundations into the virtual-memory discipline that computer systems curricula teach to this day.

Modern inference serving collided with these identical capacity limits when the autoregressive Transformer architecture made each generated token attend to key and value tensors from all prior tokens ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-vaswani2017|Vaswani et al. 2017]]). Early efforts mitigated this growth by modifying the neural network architecture itself. Multi-query attention ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-shazeer2019fast|Shazeer 2019]]) and grouped-query attention ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-ainslie2023gqa|Ainslie et al. 2023]]) reduced the memory footprint by sharing key-value heads across multiple query heads. In parallel, Pope et al. ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-pope2023efficiently|2023]]) developed an analytical framework showing that accelerator memory capacity and memory bandwidth, rather than floating-point compute throughput, impose the primary bottleneck on context length and batch concurrency.

Subsequent innovations in serving systems recapitulated the operating-systems lineage directly. Orca introduced iteration-level scheduling, enabling fine-grained preemption and dynamic batching where requests join and leave running batches on individual token boundaries ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-yu2022orca|Yu et al. 2022]]). PagedAttention adapted classical virtual paging directly to key-value cache management, using block tables and copy-on-write mechanisms to eliminate external fragmentation and reclaim the memory previously wasted by reserving contiguous worst-case sequence lengths ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-kwon2023vllm|Kwon et al. 2023]]). SGLang introduced radix-tree prefix caching with leaf-first eviction, enabling structural cache reuse across independent requests that share common system prompts or few-shot exemplars ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-zheng2024sglang|Zheng et al. 2024]]). To prevent lengthy prompt ingestions from stalling generation, Sarathi introduced chunked prefill, bounding the latency spikes that prefill operations impose on active decode iterations ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-agrawal2023sarathi|Agrawal et al. 2023]]). Finally, DistServe and Splitwise extended this decoupling across physical hardware nodes through phase disaggregation, placing the prefill and decode stages on separate, specialized worker pools ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-patel2024|Patel et al. 2024]]; [[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-zhong2024distserve|Zhong et al. 2024]]).

Agent workloads introduce the memory dilemma at the center of this chapter: execution state that idles during tool execution and subsequently resumes. When an agent invokes an external tool, its execution thread pauses while waiting for external API responses or environment feedback. During this idle window, the retained KV cache ties up expensive accelerator high-bandwidth memory. Work on tool interception formalized this challenge by framing KV cache lifecycle management around three primary operations. These were keeping the state resident in device memory, swapping it to host memory or storage, and dropping it entirely to recompute upon resumption ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-abhyankar2024infercept|Abhyankar et al. 2024]]). This trade-off balances idle memory capacity against host-to-device transfer bandwidth and compute recomputation costs. Multi-turn serving systems such as CachedAttention and Mooncake expanded this design space into multi-tier memory hierarchies, paging dormant KV caches out to host DRAM and disaggregated solid-state storage clusters ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-gao2024cachedattention|Gao et al. 2024]]; [[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-qin2024mooncake|Qin et al. 2024]]). Lossy approximation techniques pursued an alternative path, trading mathematical fidelity for reduced memory footprints through attention sinks ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-xiao2024streamingllm|Xiao et al. 2024]]) and score-based eviction policies ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-zhang2023h2o|Zhang et al. 2023]]). However, whether lossy cache approximation can reliably preserve the intricate, long-range dependencies required across extended agent trajectories remains an open systems and modeling challenge.

For readers seeking to trace the lineage from classical memory management to agent serving infrastructure, six works are especially illuminating:

- Denning ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-denning1970|1970]]) provides the foundational survey of paging, replacement algorithms, and locality of reference, showing how modern KV-cache management problems mirror classical virtual memory challenges transposed onto a new architectural storage unit.
- Denning ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-denning1968|1968a]]) introduces the working-set model, establishing the formal link between program locality and resource allocation. It provides the theoretical foundation for admission control, explaining why multi-tenant model servers must reject or queue requests when aggregate memory demand exceeds physical accelerator capacity.
- Pope et al. ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-pope2023efficiently|2023]]) develops an analytical model for large-model inference, demonstrating rigorously how attention head sharing, tensor partitioning, and memory bandwidth dictate whether a deployment is bounded by arithmetic throughput or memory capacity.
- Kwon et al. ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-kwon2023vllm|2023]]) introduces PagedAttention, adapting classical operating system paging, virtual block tables, and copy-on-write mechanisms to eliminate KV cache fragmentation in serving engines. It serves as an exemplary case study in translating classical systems principles to modern accelerator architectures.
- Zheng et al. ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-zheng2024sglang|2024]]) structures prompt cache management through radix trees, treating token prefix reuse as a first-class scheduling and eviction problem in multi-turn and agentic serving workloads.
- Abhyankar et al. ([[01 Books/Volume III - Agentic Systems/02 Agent Memory/05 KV Cache Management/V3-05.14 Source References#^ref-abhyankar2024infercept|2024]]) formalizes the tool-wait problem in agent workloads, quantifying the engineering trade-offs among retaining, swapping, and discarding KV cache state during external tool execution.
