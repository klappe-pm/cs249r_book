*Agentic Machine Learning Systems Stack*

*Agent stack focus for this chapter.*

*When is another token, candidate, check, or model call worth its cost?*

An agent that deliberates before acting pays latency and money for a better chance of success, whether it spends them on a longer derivation, more candidate patches, an extra check, or another model call. Each purchase answers a different question. More tokens re-examine what the prompt already holds, more candidates raise the chance that a good one sits somewhere in the pool, and only an executed check adds a fact the model did not have. None of them makes the returned answer correct, because a selector can return a plausible failure, and a search that optimizes against a flawed check finds the flaw faster than the fix. Deliberation is therefore a budgeted allocation problem with a stopping rule. The runtime decides where the next unit of work goes, how far a passing check can be trusted, and when to stop, abstain, or escalate instead of returning its best unverified guess. Every extra turn spent inside one decision lengthens the horizon, so that spending has to be bounded before the agent acts on anything.

**Learning Objectives**

- Compare depth, breadth, and feedback as ways to spend a per-decision budget, by the information each adds, the tokens it consumes, and its critical path.
- Distinguish candidate availability from selected-output quality when evaluating voting, learned scoring, and task-specific checks.
- Calculate accepted-set precision from stated checker error rates and explain how adaptive search can change those assumptions.
- Represent a candidate plan as a dependency graph and identify which parts require revision after an observation changes.
- Analyze how step-level checks and pruning bound a search tree’s growth and its scorer cost.
- Design stopping rules that enforce resource ceilings without treating budget exhaustion as acceptance evidence.
- Evaluate competing deliberation policies under a common budget and deadline by pass probability, actual spend, and abstentions.
