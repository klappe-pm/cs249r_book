# V3-03.14 Footnotes

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03 Test-Time Compute|V3-03 Test-Time Compute]]

^footnotes

<sup>1</sup> **Origin of pass@${k}$**: The metric was introduced to score program synthesis by functional correctness rather than by textual similarity to a reference ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-kulal2019spoc|Kulal et al. 2019]]). Because plugging the observed pass fraction ${c}/{n}$ into $1-(1-{c}/{n})^{k}$ biases the estimate of what breadth buys, Chen et al. ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-chen2021evaluating|2021]]) replaced it with the combinatorial estimator derived below.

^fn1

<sup>2</sup> **Step-Level Labels (PRM800K)**: Outcome labels for code can be produced automatically by running tests. Step labels require a judgment on each intermediate step, and the PRM800K dataset used to train the process reward model of Lightman et al. ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-lightman2023let|2024]]) contains about 800,000 human step-level labels. That labeling cost is one reason learned process scorers are scarcer than outcome checks.

^fn2

<sup>3</sup> **Goodhart’s Law**: The economist Charles Goodhart stated it in 1975 about monetary policy: any observed statistical regularity tends to collapse once pressure is placed upon it for control purposes ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-goodhart1984|Goodhart 1984]]). The anthropologist Marilyn Strathern later gave it the form usually quoted today, that when a measure becomes a target it ceases to be a good measure ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-strathern1997improving|Strathern 1997]]). A test suite used to select patches is such a regularity, a reliable description of past candidates that weakens once search optimizes against it.

^fn3

<sup>4</sup> **Extreme-Value Asymptotics**: The form ${\sigma}\sqrt{2\ln {N}}$ is only the leading term of the Gaussian maximum, and convergence is slow, which is why the chapter computes the exact expectation beside it. The Gaussian is also a favorable case. Scoring errors with heavier tails, such as a learned judge that occasionally misjudges badly, push the selected error up faster than $\sqrt{\ln {N}}$, so the drift in a real pool can exceed this estimate.

^fn4

<sup>5</sup> **Dependency-Driven Rebuilding**: Build tools solved the same problem for files. Make rebuilds a target only when one of its declared prerequisites is newer than the target ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-feldman1979make|Feldman 1979]]), and its characteristic failure is the one described here, in which an undeclared dependency leaves a stale target that looks up to date. The saving is only as sound as the recorded edges.

^fn5

<sup>6</sup> **Beam Search**: The method first appeared in the HARPY speech recognition system, which advanced only a small set of the best-scoring partial paths at each step instead of the full search space ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-lowerre1976|Lowerre 1976]]). It accepted a bounded risk of pruning the eventual best path in exchange for bounded time and memory, the same trade a runtime makes when it retains a fixed number of partial candidates.

^fn6

<sup>7</sup> **From UCT to PUCT**: The UCT rule treated each node’s choice of extension as a multi-armed bandit, adding an exploration bonus that shrinks as an extension accumulates visits ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-kocsis2006bandit|Kocsis and Szepesv’ari 2006]]). PUCT weights that bonus by a predictor’s prior over the arms ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-rosin2011multi|Rosin 2011]]), which is what lets a language model’s own step probabilities concentrate a small budget on plausible extensions. A miscalibrated prior steers visits away from correct but unlikely steps just as effectively.

^fn7

<sup>8</sup> **Galton–Watson Process**: The model comes from a Victorian question about the extinction of family surnames, analyzed in 1875 ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-watson1875probability|Watson and Galton 1875]]). That analysis wrongly concluded that every line dies out; the correct result is the threshold used here, under which extinction is certain when the mean number of surviving offspring is at most one (excluding the degenerate case of exactly one child every time) and avoidable when it exceeds one. For a search tree the surviving offspring are the children that pass the step check, so the rejection rate decides which side of the threshold the search lands on.

^fn8

<sup>9</sup> **Satisficing**: Herbert Simon borrowed the word in 1956 to describe a chooser who stops at the first alternative meeting an aspiration level, because a decision maker with limited capacity cannot afford an exhaustive search for the best ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-simon1956rational|Simon 1956]]). A runtime’s acceptance criteria play the role of that aspiration level, which is why they must be fixed before search begins rather than lowered as the budget runs out.

^fn9

<sup>10</sup> **Sequential Stopping**: Statistics made stopping part of an experiment’s design with the sequential probability ratio test, which after each observation decides whether to accept, reject, or sample again ([[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.13 Source References#^ref-wald1945sequential|Wald 1945]]). Such tests reach a verdict with fewer observations on average than a fixed-size test with the same error rates. The marginal rule borrows that structure, although its threshold is an economic choice rather than an error rate.

^fn10

<sup>11</sup> **Two Error Denominators**: The fraction of incorrect candidates that pass is the check’s false positive rate, ${\epsilon_{\text{FA}}}$ in this chapter; the fraction of accepted outputs that are incorrect is the false discovery rate, $1-{\Pi_{V}}$. [[01 Books/Volume III - Agentic Systems/01 The Model/03 Test-Time Compute/V3-03.05 Verifying Candidates#^eq-vol3-verifier-precision|Equation 3]] connects them only through the valid-candidate rate, so a report that gives one without the base rate cannot be converted into the other.

^fn11
