# V3-18.07 Correlated Ensemble Failures

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18 Multi-Agent Coordination|V3-18 Multi-Agent Coordination]]

^sec-vol3-multiagent-consensus

Adding a panel of five model reviewers to `migration_task_01` to check semantic correctness before publication exposes the same shared-assumption hazard. All five reviewers may endorse `worker_caller_01`’s patch because they share the mistaken assumption that the legacy interface remains available, accumulating approvals without ever verifying the underlying dependency. This synchronized breakdown illustrates a **correlated failure**, in which the reviewers fail on the same inputs. When individual agents share systemic blind spots, consensus among them is informative only up to the limits of their joint error distribution.

### Shared Difficulty and Conditional Independence

^sec-vol3-multiagent-shared-difficulty

Two classical foundations in fault tolerance appear to promise the opposite. Condorcet’s jury theorem ([[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.15 Source References#^ref-condorcet1785essai|Condorcet, Marquis de 1785]]) states that if independent voters are each correct with probability above one half, the probability that a majority vote is correct approaches one as voters are added. In computer engineering, N-modular redundancy applies the identical arithmetic to hardware, masking a faulty replica through majority voting circuits ([[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.15 Source References#^ref-vonneumann1956probabilistic|Neumann 1956]]). Both guarantees rest on a basic premise: that individual voters or components fail independently given the ground truth. Software engineering discovered during the 1980s that this premise breaks down in practice. Independently developed program versions failed on identical inputs far more frequently than statistical independence predicted[[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.16 Footnotes#^fn7|⁷]] ([[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.15 Source References#^ref-knight1986experimental|Knight and Leveson 1986]]). [[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.07 Correlated Ensemble Failures#^tbl-vol3-nmr-vs-review-ensembles|Table 6]] contrasts the physical roots of independence in hardware redundancy with the fragile assumptions underlying model reviewer ensembles.

| Question                | Replicated hardware under majority vote                      | Model reviewers under majority vote                                            |
|:------------------------|:-------------------------------------------------------------|:-------------------------------------------------------------------------------|
| Source of independence  | Physically separate faults such as particle strikes and wear | Must be established; shared training, prompts, and inputs can correlate errors |
| What a replica checks   | The same deterministic computation                           | A judgment about a candidate whose difficulty is shared by every reviewer      |
| What adding voters buys | Majority error falls rapidly when faults are independent     | Gain depends on the joint error model and may level off at a floor             |

Table 6: **Redundancy with and without Independent Faults**: Majority voting inherits its guarantee from independent failures, an assumption that must be justified for both replicated hardware and model reviewers.

^tbl-vol3-nmr-vs-review-ensembles

To quantify how correlation degrades redundancy, consider a binary review process evaluating candidate artifacts known to violate an acceptance criterion. Let ${X}_j=1$ denote the event where reviewer ${j}$ erroneously approves an invalid candidate, with marginal false-approval probability ${p}$ over this candidate population. If an ensemble of ${N_{\text{workers}}}$ reviewers makes independent errors with identical probability ${p}$, their total number of false approvals ${N_{\text{fa}}}$ follows a binomial distribution. For an odd ensemble size ${N_{\text{workers}}}$, a faulty majority forms with probability

$$
\Pr({N_{\text{fa}}}>{N_{\text{workers}}}/2)=\sum_{k=({N_{\text{workers}}}+1)/2}^{{N_{\text{workers}}}}\binom{{N_{\text{workers}}}}{{k}}{p}^{k}(1-{p})^{{N_{\text{workers}}}-{k}}.
$$

Statistical independence must always be stated relative to the information held fixed. Repeated, independently sampled calls to a single model on one fixed input prompt can be conditionally independent. However, candidate defects vary widely in real workloads: some bugs are subtle and intricate, whereas others are straightforward. A challenging candidate is difficult for every reviewer. Across the broader candidate population, individual reviewer errors become positively correlated. Furthermore, multi-agent debate protocols introduce an intentional communication channel where agents revise their answers after inspecting peer conclusions ([[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.15 Source References#^ref-du2023improving|Du et al. 2023]]). This deliberate coupling introduces a secondary layer of dependence on top of shared task difficulty.

A latent-propensity model makes this shared difficulty explicit. Eckhardt and Lee originally introduced this framework to explain coincident software failures ([[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.15 Source References#^ref-eckhardt1985theoretical|Eckhardt and Lee 1985]]), assigning each candidate input an intrinsic propensity ${Q} \in [0, 1]$ of causing a randomly chosen version to fail. In an agent review setting, draw a candidate with false-approval propensity ${Q}$. Conditional on ${Q}$, each reviewer independently issues an erroneous approval with probability ${Q}$. Reviewers share the candidate’s intrinsic difficulty, even though their individual sampling realizations remain independent. On a candidate of propensity ${Q}$, two distinct reviewers therefore err together with probability ${Q}^2$. Averaging across the candidate population gives a marginal false-approval rate of ${p}=\mathbb{E}[{Q}]$ and a joint error probability of $\mathbb{E}[{Q}^2]$, so subtracting ${p}^2$ leaves a pairwise covariance equal to $\operatorname{Var}({Q})$, which divides by the marginal Bernoulli variance ${p}(1-{p})$ to give the correlation coefficient ${\rho}$:

$$
{p}=\mathbb{E}[{Q}],\qquad \operatorname{Cov}({X}_i,{X}_j)=\operatorname{Var}({Q}),\qquad {\rho}=\frac{\operatorname{Var}({Q})}{{p}(1-{p})}\quad({i}\ne {j}).
$$

To model this variation analytically, assume ${Q}\sim\operatorname{Beta}({a},{b})$, a flexible density on $[0,1]$ with positive shape parameters ${a}$ and ${b}$. Its mean is ${a}/({a}+{b})$, and for reviewers who share ${Q}$ the pairwise correlation works out to $1/({a}+{b}+1)$, so a small ${a}+{b}$ means candidates differ widely in difficulty and errors correlate strongly. Setting the mean to the marginal rate and the correlation to the target gives ${a}+{b}={\rho}^{-1}-1$, which implies ${a}={p}({\rho}^{-1}-1)$ and ${b}=(1-{p})({\rho}^{-1}-1)$ for $0<{p}<1$ and $0<{\rho}<1$. Compounding the conditional binomial distribution over this beta prior yields the beta-binomial probability for ${k}$ false approvals:

$$
\Pr({N_{\text{fa}}}={k})=\binom{{N_{\text{workers}}}}{{k}}\frac{\mathrm{B}({k}+{a},{N_{\text{workers}}}-{k}+{b})}{\mathrm{B}({a},{b})},
$$

where $\mathrm{B}$ denotes the beta function. A stipulated marginal error rate and pairwise correlation do not uniquely determine the full joint distribution, and the beta family represents an idealized model for shared difficulty. Consequently, any production deployment must empirically measure its joint error distribution directly on domain-specific candidates.

↪ The derivation of the beta-binomial false-approval count from the latent-propensity model is developed in **[[05 Reference/Volume III - Agentic Systems/V3 Mathematical Foundations#^sec-vol3-appendix-math-correlated-quorum|Correlated failures in multi-agent quorum voting]]**.

**Napkin Math 18.4: What the joint error model changes**

**Problem**: Five reviewers assess known-invalid candidates, each with marginal false-approval probability ${p}=0.20$. How often does a majority falsely approve if their errors are independent, and how often under the beta mixture at ${\rho}=0.40$?

**Math**: Summing the binomial masses for three or more false approvals gives 5.79 percent under independent errors. The beta-binomial masses with ${a}={p}({\rho}^{-1}-1)$ and ${b}=(1-{p})({\rho}^{-1}-1)$ give 16.68 percent. Unanimous false approval changes from 0.032 percent to 3.92 percent.

**Systems insight**: At the same marginal error rate, positive correlation erases most of the reliability gains expected from voting. The mixture’s majority improves only slightly on a single reviewer’s marginal rate ${p}$, and a unanimous false approval is about 122 times as likely as independence predicts. Before adding reviewers to an ensemble, estimate ${\rho}$ empirically on known-invalid candidates. When correlation is high, spending additional token budget on more reviewers of the same type yields diminishing returns. That budget is better spent on independent, deterministic validation checks. These calculations condition on the candidate being invalid; the overall probability that an approved candidate is invalid also depends on the prevalence of invalid candidates in the workload.

The mixture model also bounds what ensemble scaling can achieve. Conditional on a candidate’s propensity ${Q}$, the weak law of large numbers implies that the fraction of reviewers falsely approving converges to ${Q}$ as the ensemble grows. Consequently, an arbitrarily large majority vote falsely approves precisely those candidates with ${Q}>1/2$. Rather than decaying toward zero, majority false approval approaches a nonzero asymptotic floor at $\Pr({Q}>1/2)$.

Under the parameters modeled in the notebook, that floor is 15.0 percent. At 15 reviewers, independent errors would reduce majority false approvals to 0.42 percent, whereas the beta mixture leaves the error rate stalled at 15.6 percent. In [[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.07 Correlated Ensemble Failures#^fig-vol3-correlated-ensemble-failure|figure 4]] the independent curve keeps falling toward zero while the mixture curve flattens just above the floor. At five reviewers the mixture moves probability to the extremes, so a candidate is approved by no one or by a majority far more often than independence predicts. Tripling the committee from five to 15 reviewers of the same kind triples review spend yet lowers majority false approval only from 16.68 percent to 15.6 percent, because the remaining errors concentrate on candidates that every such model finds difficult.

### Evidence at the Integration Boundary

^sec-vol3-multiagent-integration-evidence

In an automated workflow such as `migration_task_01`, five reviewers that all repeat the assumption that the old interface remains available provide essentially a single effective observation. Their consensus should not trigger an automatic merge; instead, it should trigger an end-to-end integration check that evaluates the modified caller alongside the updated callee interface. A protected, deterministic check supplies ground-truth evidence that model reviewers cannot fabricate. A compiler establishes whether the candidate compiles cleanly under the target configuration, and a regression test suite confirms that specified functional behaviors remain intact. If an untrusted worker agent modifies a test suite to bypass a signature verification check, the test may pass while completely failing to validate the security property. This vulnerability is why authoritative evaluation suites must remain isolated behind a protected grading boundary. Even so, deterministic validation remains bounded by test suite coverage gaps and flawed formal specifications.

Classical distributed quorum protocols cannot rescue a review ensemble plagued by correlated errors. When a large language model (LLM) outputs well-formed, plausible, yet incorrect evidence, it produces a fail-plausible fault rather than a fail-stop crash. In the unsigned-message protocol model, Byzantine agreement guarantees consensus despite arbitrary faults only while faulty participants remain strictly below one third of the ensemble[[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.16 Footnotes#^fn8|⁸]] ([[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.15 Source References#^ref-lamport1982byzantine|Lamport et al. 1982]]). Because reviewers that share training distributions, system prompts, or upstream reasoning summaries fail together, correlated errors can push the faulty fraction past that one-third threshold regardless of replica count. Requiring each reviewer to inspect primary evidence before viewing peer conclusions (information isolation) removes direct peer influence. Distinct model architectures, diversified prompts, and separate evidence sources lower ${\rho}$ only as far as empirical measurement on known-invalid candidates demonstrates.

↩︎ The fail-plausible fault, output that is well formed and plausible yet wrong, is established in **[[01 Books/Volume III - Agentic Systems/00 Introduction/01 Introduction/V3-01.06 Invariant Closure#^sec-vol3-intro-fail-plausible|The fail-plausible fault]]**.

Consensus among worker agents must never be confused with authoritative execution privilege. Reviewer agreement provides an informative heuristic signal within the bounds defined by an orchestration workflow. Merging code, publishing artifacts, broadening task scopes, or bypassing gate checks requires explicit capability grants issued by a privileged control plane. Even unanimous approval from the five reviewers in `migration_task_01` only advances the candidate to the integration gate, where the runtime still checks its scope, dependencies, and publication grant before updating the branch.

**Checkpoint 18.2: Interpreting concurrent results and agreement**

**Clean merge vs. valid change**: Why do disjoint write paths leave the caller patch unvalidated after an interface change, and which record lets the integration service decide?

**Collision estimate**: A repository has 2,000 files and each worker writes 10. Using [[01 Books/Volume III - Agentic Systems/06 Agents at Scale/18 Multi-Agent Coordination/V3-18.06 Optimistic Concurrency Control#^eq-vol3-multiagent-write-collision|equation 4]], roughly how many workers make a shared write more likely than not? Should the runtime isolate workers at that size?

**Reviewer budget**: Majority false approval is 16.68 percent at five reviewers and levels off near 15.0 percent. Should the system provision ten more reviewers of the same kind, or one protected test, and why?

**Approval vs. authority**: Distinguish a worker’s approval, a scoped protected-test result, and permission to publish the candidate.

Validation evidence also carries a finite lifetime while asynchronous workers execute in parallel. If an upstream orchestrator rejects an intermediate candidate patch or alters its task plan, downstream worker agents may continue computing on stale state. Robust agent runtimes must invalidate and reject superseded work while properly terminating and accounting for in-flight child processes.
