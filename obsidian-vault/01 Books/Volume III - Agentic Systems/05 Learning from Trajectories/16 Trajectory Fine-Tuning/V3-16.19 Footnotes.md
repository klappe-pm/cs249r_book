# V3-16.19 Footnotes

[[Home|Home]] · [[01 Books/Volume III - Agentic Systems/Volume 3 Overview|Volume Overview]] · [[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16 Trajectory Fine-Tuning|V3-16 Trajectory Fine-Tuning]]

^footnotes

<sup>1</sup> **Teacher Forcing**: Williams and Zipser ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-williams1989learning|1989]]) named the technique for recurrent networks, feeding the recorded target back as the next input instead of the network’s own output. Because every prefix is recorded rather than generated, a causal model computes all of an example’s next-token predictions in one parallel forward pass, which is why imitating a trajectory costs one pass per example rather than one sampled rollout per decision.

^fn1

<sup>2</sup> **Causal Self-Attention**: Causal masking in Transformer decoders restricts each token from attending to subsequent positions ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-vaswani2017|Vaswani et al. 2017]]). The same triangular structure enforces the label shift: the network predicts ${x}_t$ using only the representation formed at ${t}-1$.

^fn2

<sup>3</sup> **Cross-Contamination**: Krell et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-krell2021efficient|2021]]) used the term for attention and label leakage between sequences packed into one buffer, and showed that masks, position resets, and per-sequence loss handling make a packed model mathematically equivalent to the unpacked one. The equivalence is the property to test: a packed loader that trains faster but lets examples read one another has changed the learning problem, and no loss curve will show it.

^fn3

<sup>4</sup> **Exposure Bias**: Ranzato et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-ranzato2016sequence|2016]]) introduced the name for text generators trained on reference words and run on their own. Control researchers had met the same effect earlier as the compounding error of behavioral cloning, which Ross and Bagnell ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-ross2010efficient|2010]]) bounded. The two literatures describe one mechanism, and agents inherit the control version: a wrong action changes the environment, not just the phrasing.

^fn4

<sup>5</sup> **DAgger’s Mixing Schedule**: Ross et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-ross2011reduction|2011]]) require only that the average reference-execution probability tend to zero over rounds, and report that the simplest schedule, executing the reference only in the first round, often performs best. The systems cost sits elsewhere: every visited state needs a reference label on demand, so the labeler is an online service in the collection loop rather than a one-time annotation pass.

^fn5

<sup>6</sup> **Bradley–Terry Model**: The paired-comparison model of Bradley and Terry ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-bradley1952rank|1952]]) gives the probability that item ${i}$ is preferred to item ${j}$ as a logistic function of the difference of their latent scores. Only score differences are identified, which is why DPO’s implied reward carries an input-dependent constant that cancels within a pair, and why a DPO score has no meaning outside the comparison that produced it.

^fn6

<sup>7</sup> **Context Distillation**: Askell et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-askell2021general|2021]]) introduced the term for training a model without a long prompt to match the output distribution the same model produced with it, motivated by context-window limits and the compute required to process prompt prefixes repeatedly.

^fn7

<sup>8</sup> **Soft Targets**: Buciluă et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-bucilua2006model|2006]]) compressed large ensembles by labeling data with the ensemble’s predictions and training a small network on those labels; Hinton et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-hinton2015distilling|2015]]) named the method distillation and trained on the teacher’s temperature-softened probabilities over every class. Soft targets require the teacher’s logits; a collector that sees only sampled messages has one token per position instead of a distribution.

^fn8

<sup>9</sup> **Adapter Modules**: Houlsby et al. ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-houlsby2019parameter|2019]]) introduced adapters as small bottleneck layers inserted inside each Transformer block, updating only those bottleneck parameters per task. However, inserting sequential layers introduces serial computational dependencies during inference. Low-rank adaptation avoids this serving latency by parameterizing updates to match the exact dimensions of existing weight matrices, enabling operators to fold the adapter directly into the base weights when serving without adding serial layer overhead.

^fn9

<sup>10</sup> **Low Intrinsic Rank**: Hu and colleagues motivated LoRA by hypothesizing that weight updates during downstream adaptation lie on a manifold with low intrinsic dimension, showing that small ranks (${r} \in \{4, 8\}$) matched full fine-tuning on standard language benchmarks ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-hu2021lora|Hu et al. 2021]]). That empirical finding reflects the characteristics of those benchmark tasks rather than a universal theoretical guarantee. Fine-tuning an agent policy on novel tool invocation protocols or structured error recovery often demands specialized capacity, making systematic rank sweeps essential under the evaluation contract of this chapter.

^fn10

<sup>11</sup> **Catastrophic Forgetting**: McCloskey and Cohen ([[01 Books/Volume III - Agentic Systems/05 Learning from Trajectories/16 Trajectory Fine-Tuning/V3-16.18 Source References#^ref-mccloskey1989catastrophic|1989]]) showed that a connectionist network trained sequentially on a new task can lose an earlier one almost entirely, because both share the same weights. A repair-trained policy shares its weights with every other behavior the agent still needs, so retention is measured on the release’s required task set rather than assumed from a narrow training corpus.

^fn11
