# V2-14.09 Robustness of Generative Models

[[Home|Home]] · [[01 Books/Volume II - Scaling/Volume 2 Overview|Volume Overview]] · [[01 Books/Volume II - Scaling/04 The Responsible Fleet/14 Robust AI/V2-14 Robust AI|V2-14 Robust AI]]

^sec-robust-ai-robustness-generative-ai-941b

An aligned language model of the Archetype A (GPT-4/Llama-3) class can pass its safety evaluations and still comply with a harmful request once an automatically optimized suffix is appended to the prompt, and suffixes optimized against open models transfer to other models ([[01 Books/Volume II - Scaling/04 The Responsible Fleet/14 Robust AI/V2-14.14 Source References#^ref-zou2023|Zou et al. 2023]]). That suffix is an adversarial example in token space, found by gradient-guided search over discrete tokens rather than continuous pixels. Generative models also fail without any attacker. Their output is open-ended text rather than a label, so the robustness question changes from whether a label flips under perturbation to whether the generated content preserves factuality, policy constraints, and task intent across prompt variations. A fluent answer can be factually baseless while latency and uptime stay healthy, which makes hallucination the generative form of silent failure.

The evaluation discipline of [[01 Books/Volume II - Scaling/04 The Responsible Fleet/14 Robust AI/V2-14.04 A Unified Framework for Robust AI#^tbl-robust-ai-evaluation-matrix|table 1]] carries over with three adjustments. First, correctness needs a named reference. A hallucination rate is meaningful only against a stated evidence source, such as the retrieved context, a verified knowledge base, or an expert-labeled answer set, and it counts the generated claims that this reference does not support. The measured rate also depends on the model, the retrieval context, the prompt design, and the sampling temperature, so a reported rate holds only for its prompt set and decoding settings and cannot be carried to another domain without re-measurement. Second, the perturbation budget becomes a family of prompt variations. Paraphrases, reordered context, and inserted distractors play the role that the $\ell_\infty$ ball plays for an image classifier, and robustness is reported for each family. Third, the slices are domains and user populations, because an aggregate rate can hide a domain in which the model invents answers, just as the Google Photos failure hid inside aggregate image accuracy.

Detecting a hallucination on an individual request is the per-request competence problem of [[01 Books/Volume II - Scaling/04 The Responsible Fleet/14 Robust AI/V2-14.05 Environmental Shifts#^sec-robust-ai-selective-prediction|section 14.4.4]] with an open-ended output. Token entropy and log-probability can expose instability in a generation, but neither is a factuality score. A model can assign high probability to a false statement learned from its data, or low probability to a correct but rare statement. Production routing must therefore calibrate these signals against task-specific errors and combine them with evidence checks, retrieval support, or external verification.

The self-consistency technique samples multiple reasoning paths or answers for the same query. Disagreement supplies an instability signal that can route the request for review; agreement supplies weaker evidence because correlated samples can repeat the same misconception or unsupported claim. Sequence-level entropy has the same limitation: it can serve as a calibrated routing feature for a named task, but it does not transform uncertainty into truthfulness.

The signal also has a price. Each additional sample repeats the decode phase for that request, so drawing ${k}$ samples multiplies its decode work roughly ${k}$-fold; only the prompt’s prefill can be shared, when the serving system reuses the prompt’s cached key-value state. Like the noise samples of randomized smoothing, this cost lands on the compute term of every request it covers, and the same remedy applies. The expensive signal should be spent on the requests whose cheap signals already indicate uncertainty rather than on all traffic. The operational contract must measure error conditional on the routing score and provision the refusal, retrieval, tool, or human path that receives flagged generations.

↩︎ Reuse of a shared prompt’s cached key-value state across requests is established in **[[01 Books/Volume II - Scaling/03 The Fleet in Production/10 Serving at Scale/V2-10.08 Memory and Decode-Time Management#^sec-inference-scale-prefix-caching-8e8b|Prefix caching]]**.

In retrieval-augmented generation (RAG) architectures, which retrieve documents at inference time and place them in the prompt, robustness depends heavily on the quality of the retrieved context. **Retrieval noise**, the injection of irrelevant or conflicting documents into the prompt, can distract the model, causing it to ignore its internal parametric knowledge and propagate errors from the context. Robust RAG deployments can use re-ranking models, which reorder retrieved documents by relevance to the query, and context verifiers, which check each document before it enters the prompt, to filter out noise before it reaches the generation step. Their evaluation must separate retrieval failure from generation failure. Measuring answer support separately for requests whose retrieved context contains the answer and for requests whose context does not shows whether errors come from the retriever or from a model that ignores or overrides good evidence. The retrieval corpus is also an input an attacker may be able to write to, so a planted document can corrupt retrieval evidence or carry prompt injection, and the ingress controls of [[01 Books/Volume II - Scaling/04 The Responsible Fleet/14 Robust AI/V2-14.08 Data Poisoning Defenses#^sec-robust-ai-data-poisoning-defenses-d070|section 14.7]] apply to it. It becomes a training-poisoning path if the pipeline later admits it into learning.

↩︎ Retrieval-augmented generation, which keeps domain knowledge in a document index rather than in model weights, is established in **[[01 Books/Volume II - Scaling/03 The Fleet in Production/12 ML Operations at Scale/V2-12.10 Fleet Economics and Utilization#^sec-ml-operations-scale-rag-vs-finetuning-knowledge-operations-tradeoff-77f3|Retrieval-augmented generation vs. fine-tuning]]**.

Language interfaces also carry the input-level attacker into text. Prompt injection, a failure of the boundary between control and data, embeds instructions in user content or retrieved documents so that the model overrides its system prompt. The payload can arrive through a legitimate input channel, so permission to submit content does not make that content trustworthy. External access controls still constrain which data or tools the surrounding system exposes. From the robustness side, evaluation asks whether the content induces behavior outside the intended output contract. It is measured the way adversarial robustness is measured, as an attack success rate over an injection suite matched to the threat model, run by an evaluator who knows the system prompt and filters. Keeping those details secret is not a defense, because an attacker can optimize injection suffixes on other models and those suffixes can transfer to the deployed one.

↩︎ Prompt injection as a failure of the boundary between control and data is established in **[[01 Books/Volume II - Scaling/04 The Responsible Fleet/13 Security & Privacy/V2-13.06 Model-Specific Attack Vectors#^sec-security-privacy-llmspecific-threat-vectors-65f2|LLM-specific attack vectors]]**.

A common deployment pattern adds **output guardrails**, lightweight classifiers that scan generated text for policy violations or toxicity before the response returns to the user. A guardrail threshold trades the same two quantities as a selective-prediction threshold. Each false positive refuses or escalates a legitimate response, so the false-positive rate multiplied by the legitimate-request rate estimates false refusals or escalations; each false negative is residual risk that reaches the user. Total diverted load also includes correctly flagged harmful responses. The arrival rate at each refusal, retrieval, or human path is the incoming request rate multiplied by the fraction routed to that path under the policy, counting both true and false flags. Choosing the threshold from a curve measured on representative traffic, rather than from the classifier’s default, allows the team to compare that load with the path’s capacity. The guardrail also adds a model inference to every response, so its latency counts against the serving deadline. Because a guardrail is itself a model with its own decision boundary, it carries the same obligation as any other defense and must pass the adaptive evaluation of [[01 Books/Volume II - Scaling/04 The Responsible Fleet/14 Robust AI/V2-14.07 Adversarial Defenses#^sec-robust-ai-evaluation-testing-4b54|section 14.6.1.3]] against an attacker who knows it is there.

Every routing signal for generative models, from token entropy to a guardrail score, is also computed by the same serving system that the remaining pillar can corrupt.

**Self-Check: Question**

1.  A team reports that its retrieval-augmented assistant has a 3 percent hallucination rate and proposes quoting that figure for a new legal-research deployment. Which condition must hold before the figure says anything about the new deployment?

    1.  The rate must be re-measured against a stated evidence source on the new domain’s prompt set with the same retrieval context and decoding settings.
    2.  The model’s mean token entropy on the new domain must be no higher than on the original domain.
    3.  The new deployment must use self-consistency sampling, because agreement among samples certifies factuality.
    4.  No condition is needed, because a hallucination rate is a property of the model weights alone.

2.  In large language models, robustness failures manifest as confident, fluent hallucinations rather than discrete label misclassifications. Describe two uncertainty quantification mechanisms used to detect semantic instability in generative AI and explain their systems trade-offs.
